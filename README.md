# Codex 技能合集（236 个）

AI CLI 的「Codex 技能合集」从这个分支下载：可以一键全部安装，也可以按类别安装。

- `skills/`：236 个技能，每个目录一个 `SKILL.md`
- `manifest.json`：分类和技能清单（AI CLI 按它分组安装）
- `SOURCES.csv`：每个技能能查到的原始来源（GitHub 仓库或候选地址），版权归原作者

| 分类 | 数量 |
|---|---:|
| 内容创作与社交媒体 | 35 |
| 编程开发、云服务与安全 | 32 |
| 图像、视频、音频与设计 | 28 |
| Agent、技能与工作流增强 | 24 |
| 教育、学术与研究 | 23 |
| 办公文档与文件效率 | 21 |
| 财经、数据与商业分析 | 21 |
| 电商、广告与营销运营 | 18 |
| 生活、健康、出行与兴趣 | 15 |
| 法律、政务与合规 | 10 |
| 搜索、资讯与知识管理 | 9 |

部分技能需要另外配置 API Key、Python / Node、FFmpeg 或厂商命令行工具，以各技能的说明为准。
