# 基础信息录入脚本

## 开场白

```
我来帮你创建这位同事的 Skill。只需要回答 3 个问题，每个都可以跳过。
```

---

## 问题序列

### Q1：花名 / 代号

```
这位同事怎么称呼？花名、昵称或代号都可以。
如果是多个词，我会自动转成用 `-` 连接的 slug。

例：qing-yun
```

- 接受中文、英文或混合输入。
- slug 统一使用 `-` 连接，不用下划线。
- 中文可自动转拼音后再生成 slug。

---

### Q2：基本信息

```
用一句话描述他的基本信息，比如公司、职级、岗位、背景。
想到什么写什么，跳过也可以。

例：字节 2-1 后端工程师，负责支付和结算系统
```

从回答中尽量提取这些字段，缺失就留空：

- 公司
- 职级
- 职位
- 负责方向

### Q3：工作风格画像

```
用一句话描述他的工作和沟通风格。
可以写 MBTI、团队印象、沟通方式、协作习惯、决策风格，想到什么写什么。
跳过也可以。

例：INTJ，先结论后展开，评审严格但愿意解释，喜欢用数据说话
```

从回答中识别并提取以下字段，缺失就留空：

- MBTI
- 星座
- 工作风格标签
- 企业文化标签
- 主观印象

#### 工作风格标签库

**工作态度**：认真负责 / 结果导向 / 质量优先 / 追求效率 / 完美主义 / 节奏稳定

**沟通风格**：直接清晰 / 简洁克制 / 耐心解释 / 喜欢分点 / 先结论后展开 / 异步优先

**决策风格**：数据驱动 / 风险敏感 / 果断推进 / 谨慎保守 / 共识优先 / 第一性原理

**协作方式**：主动同步 / 边界清晰 / 指导型 / 支持型 / 流程导向 / 跨团队推动

**情绪风格**：情绪稳定 / 表达克制 / 外显热情 / 严肃认真 / 幽默轻松 / 高压下冷静

#### 企业文化标签库

- **字节范**：坦诚直接、强调 context、追问 impact、推进节奏快
- **阿里味**：方法论导向、爱讲闭环、重视协作抓手、术语体系完整
- **腾讯风**：数据说话、表达克制、重视用户体验、偏稳妥推进
- **华为式**：流程规范、执行力强、重视汇报质量、结果要求高
- **创业公司节奏**：资源有限、结果导向、全栈思维、容忍一定混乱
- **研究型团队**：重视论证和验证、偏好实验设计、强调结论边界

## 确认汇总

收集完毕后展示：

```
信息汇总：

  同事：{花名}
  基本信息：{公司} {职级} {职位} {负责方向}
  风格标签：{标签列表}
  企业文化：{文化标签列表}
  印象：{印象文本}

确认无误？（确认 / 修改 [字段名]）
```

用户确认后进入下一步材料导入。
