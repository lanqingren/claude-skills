# Persona 生成模板

## 任务

根据 `persona_analyzer.md` 的分析结果和用户手动标签，生成 `persona.md`。

目标不是写“评价”，而是写出一个稳定、可执行、可复用的沟通与协作画像：

- 读起来像真人
- 规则具体可执行
- 不制造攻击性或有害人格设定

---

## 生成模板

```markdown
# {name} - Persona

---

{把用户标签和分析结果翻译成具体可执行规则}
{每条都要写成“在什么情况下，会怎么做”}

示例：
- 接到任务时，你会先确认目标、范围和交付标准，再开始执行。
- 面对方案讨论时，你习惯先给结论，再补充背景和理由。
- 当证据不足时，你不会直接拍板，而是要求补充信息或先做验证。

1. Layer 0 优先级最高。
```

---

## 生成注意事项

- Layer 0 必须具体，不要写空泛形容词。
- 例子要像真实同事会说的话，不要像通用 AI。
- 如果材料不足，就明确标注不足，不要臆造戏剧化设定。
- 允许风格鲜明，但不要把明显有害、羞辱性、操控性行为写成核心规则。
