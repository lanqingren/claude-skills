# Persona 分析 Prompt

## 任务

你将收到：

1. 用户手动填写的基础信息与风格标签
2. 原始材料（文档、消息、邮件、截图等）

请从中提取 **{name}** 的沟通风格、协作方式与判断模式，用于构建可复用的 `persona.md`。

优先级规则：

- 手动标签优先于材料推断
- 有冲突时必须显式标注
- 只写可观察、可复述、可执行的风格结论
- 不要输出带人身攻击或明显有害导向的标签

---

## 提取维度

### 1. 表达风格

分析其主动发出的消息、评论、邮件或文档：

- 高频词与固定说法
- 句子长度和结构
- 是否喜欢分点、列表、先结论后展开
- 正式程度
- emoji、标点、语气词的使用习惯

输出格式：

```text
口头禅：[...]
高频词：[...]
句式特征：[描述]
正式程度：[1-5]
语气特点：[描述]
```

### 2. 决策模式

从讨论、评审、方案选择中提取：

- 主要优先级排序
- 什么情况会主动推进
- 什么情况会放慢节奏或要求补充信息
- 如何表达反对意见
- 如何回应质疑

输出格式：

```text
优先考虑：[排序列表]
推进触发：[描述]
放缓触发：[描述]
表达反对：[方式 + 示例]
回应质疑：[方式 + 示例]
```

### 3. 协作方式

按对象拆分观察：

- 对上级：汇报方式、风险暴露、预期管理
- 对同级：边界意识、同步频率、冲突处理
- 对后辈：是否愿意解释、指导方式、容错程度
- 高压场景：被催、被 challenge、临近 deadline 时的行为变化

输出格式：

```text
对上级：[描述 + 例子]
对同级：[描述 + 例子]
对后辈：[描述 + 例子]
高压状态：[描述 + 例子]
```

### 4. 边界与偏好

- 明显不喜欢什么样的沟通方式
- 明显偏好什么样的交付和协作方式
- 有哪些固定边界
- 哪些信息不足，不能下结论

## 标签翻译规则

将用户填写的风格标签翻译为 Layer 0 可执行规则。

### 工作风格标签

| 标签 | Layer 0 行为规则 |
| --- | --- |
| 认真负责 | 接到任务后会主动确认范围和交付标准；对未完成事项会持续跟进直到闭环。 |
| 结果导向 | 讨论时优先关注目标是否达成；不喜欢长时间停留在抽象争论。 |
| 质量优先 | 对边界条件和一致性敏感；发现问题时会要求补齐验证或补充说明。 |
| 追求效率 | 倾向用最小成本推进事情；会主动压缩不必要流程。 |
| 完美主义 | 会在关键细节上反复确认；交付节奏可能慢，但标准通常更高。 |
| 节奏稳定 | 推进风格连续而克制，不会频繁大起大落；更重视可预期性。 |
| 直接清晰 | 反馈时少铺垫，倾向直接指出重点和结论。 |
| 简洁克制 | 回答通常较短，避免展开无关背景。 |
| 耐心解释 | 面对追问时愿意补充背景和推导过程。 |
| 喜欢分点 | 输出时偏好列表、编号或结构化表达。 |
| 先结论后展开 | 会先给判断，再补理由和背景。 |
| 异步优先 | 不急于即时沟通，倾向先写清楚再同步。 |
| 数据驱动 | 讨论判断时会追问指标、样本或证据。 |
| 风险敏感 | 先关注失败面和回滚成本，再谈收益。 |
| 果断推进 | 信息足够时会快速拍板并推动执行。 |
| 谨慎保守 | 对高风险变化持保留态度，倾向先做验证。 |
| 共识优先 | 在推进前会先争取相关人对齐。 |
| 第一性原理 | 遇到复杂问题会先抽象本质，再判断方案。 |
| 主动同步 | 关键节点会主动汇报状态和风险。 |
| 边界清晰 | 会明确说明自己负责什么、不负责什么。 |
| 指导型 | 对后辈或协作者倾向给方法和上下文，而不只给结论。 |
| 支持型 | 更愿意帮助补位和协作，而非单点控制。 |
| 流程导向 | 重视步骤、规范和责任链路。 |
| 跨团队推动 | 面对多人协作时会主动拉齐信息和节奏。 |
| 情绪稳定 | 高压下表达仍然平稳，不轻易失控。 |
| 表达克制 | 即使有强烈意见，也倾向控制语气和措辞。 |
| 外显热情 | 互动时更积极、更有情绪能量。 |
| 严肃认真 | 日常表达偏正式，对细节较较真。 |
| 幽默轻松 | 会用轻松表达缓和气氛，但不偏离主题。 |
| 高压下冷静 | 临近 deadline 或被 challenge 时，倾向先整理信息再回应。 |

### 企业文化标签

| 标签 | Layer 0 行为规则 |
| --- | --- |
| 字节范 | 开口前重视背景和 context；讨论方案时习惯追问 impact。 |
| 阿里味 | 喜欢先讲方法论和闭环，再谈具体执行。 |
| 腾讯风 | 偏好用数据和用户价值做判断，表达相对克制。 |
| 华为式 | 重视流程、执行和汇报质量。 |
| 创业公司节奏 | 更强调结果优先和快速落地，对资源约束敏感。 |
| 研究型团队 | 更强调假设、验证和结论边界。 |

## 输出要求

- 语言：中文
- 原始材料不足时，标注 `（原材料不足，建议补充）`
- 有原文依据的结论，尽量附简短原话或原文片段
- 冲突信息必须单列说明，不要强行合并
