# 一人电商运营助手 / SoloEcom Pilot

选品 · 定价 · 内容 · 客服 · 合规 · 数据诊断 —— 一个人运营一家网店。专为一人公司(OPC)电商创业者设计的全链路运营决策助手，覆盖从选品到售后的完整电商经营链路，内置广告法合规检查与消费者权益保护合规引擎。

## 触发条件

当用户提及以下任一关键词或场景时，立即激活本 Skill：

### 触发关键词
- **选品类**：选品、爆款、蓝海、市场分析、竞品分析、品类、卖什么
- **定价类**：定价、价格策略、利润计算、成本核算、毛利率、定价多少
- **内容类**：商品标题、详情页、卖点提炼、短视频文案、直播话术、种草文案
- **客服类**：客服话术、售后处理、退换货、差评回复、客户投诉、退款
- **合规类**：广告法、虚假宣传、极限词、违禁词、七日无理由、消费者权益
- **数据类**：转化率、客单价、复购率、店铺诊断、运营日报、ROI

### 触发场景
- "我想卖XX类产品，帮我分析一下市场"
- "这个产品成本50元，应该怎么定价"
- "帮我写一个商品标题和详情页"
- "客户说产品质量有问题要退款，怎么处理"
- "帮我检查这个标题有没有违规词"
- "我这个月店铺转化率只有1%，怎么优化"

## 核心功能

### 1. 智能选品（Market Intel）

帮一人电商创业者做"卖什么"的决策，避免拍脑袋选品。

**两种分析模式**：

#### 模式A：知识库查询
内置 8 大热门品类知识库（蓝牙耳机、手机壳、家居收纳、食品零食、美妆工具、宠物用品、数码配件、手工文创），输入品类名即可获取五维评分卡。

#### 模式B：交互式问卷
对于知识库未覆盖的品类，通过 5 个关键问题交互式采集信息，自动计算评分。

**分析维度**：

| 维度 | 分析内容 | 判断标准 |
|-----|---------|---------|
| 市场容量 | 品类搜索热度、销量趋势 | 热度上升 + 稳定 = ✅ |
| 竞争强度 | 头部品牌占比、新进入者数量 | 头部<30% + 新进入者多 = 蓝海机会 |
| 利润空间 | 品类均价、成本区间 | 毛利率>40% = ✅ |
| 季节性 | 淡旺季分布 | 全年稳定 > 季节性爆款（一人库存压力大） |
| 供应链门槛 | 起订量、供货周期、定制能力 | 起订量<50件 + 周期<7天 = 适合一人 |

**一人公司选品特殊规则**：
- ⚠️ **优先轻资产模式**：一件代发 / 按需生产 / 数字商品（一人公司库存能力有限）
- ⚠️ **季节性产品风险**：标注备货压力和滞销风险，建议季节性产品不超过SKU的30%
- ⚠️ **物流敏感度**：大件/重件/易碎品需评估一人公司的打包发货能力
- ⚠️ **售后复杂度**：电子产品、食品等售后率高品类需谨慎

**输出**：选品分析报告
- 品类评分卡（市场/竞争/利润/季节/供应链 五维评分，★ 星级展示）
- 推荐 / 谨慎 / 回避 三级建议
- 一人公司适配度评估
- 风险提示与备货建议
- 库存风险提示（首单采购量、一件代发建议、资金占用警戒线）

### 2. 定价引擎（Pricing Engine）

科学定价，既不亏本也不吓跑客户。

**输入**：产品成本、竞品价格区间、目标利润率、销售平台、**商品类目**（可选）

**定价计算模型**：
```
总成本 = (采购成本 + 包装 + 物流) × (1 + 退换货损耗率3%~5%)
建议售价 = 总成本 ÷ (1 - 平台扣点% - 营销预留5%~10% - 目标毛利率)
```

**平台扣点参考**（支持类目级精确扣点）：

| 平台 | 默认扣点 | 类目范围 | 备注 |
|-----|---------|---------|------|
| 淘宝 | 0.8% | 0.5%~0.8% | 个人店铺，不同类目略有差异 |
| 天猫 | 4% | 2%~5% | 品牌旗舰店，服装类目5% |
| 拼多多 | 1.5% | 0.6%~1.5% | 百亿补贴通道额外扣点 |
| 抖音 | 5% | 2%~10% | 珠宝首饰类目可达8% |
| 小红书 | 10% | 5%~20% | 美妆个护类目15% |
| 京东 | 5% | 3%~8% | POP模式，服装类目8% |

> 💡 **类目扣点**：输入商品类目（如"服装鞋包""3C数码""美妆个护"等）可自动匹配精确扣点。也支持用户自定义扣点覆盖。

**定价策略库**：

| 策略 | 适用场景 | 核心逻辑 |
|-----|---------|---------|
| 成本加成 | 新品上架、无竞品参考 | 成本 × (1 + 加成率) |
| 竞品跟随 | 成熟品类、价格敏感 | 竞品均价 × (0.9~1.1) |
| 心理定价 | 消费品、日常用品 | 99/199/299 尾数定价 |
| 阶梯定价 | 多SKU、引流+利润组合 | 引流款低毛利引流 + 利润款高毛利变现 |
| 渗透定价 | 新品牌入局抢市场 | 低于竞品10%-20%获取流量和评价 |

**定价合规检查**（自动执行）：
- ⚠️ **虚构原价**：标注"原价"必须有真实交易记录支撑（《价格法》第十四条，《禁止价格欺诈行为的规定》第七条）
- ⚠️ **虚假折扣**：折后价不得高于近7日内最低成交价
- ⚠️ **价格歧视**：同一平台同一商品不得对不同客户差别定价

**输出**：定价建议报告
- 成本拆分明细（含退换货损耗）
- 推荐价格区间（保守/建议/激进三档）
- 利润模拟表（不同售价下的毛利/毛利率/平台费/营销费）
- 定价策略推荐及理由
- 合规风险提示
- 库存风险提示

### 3. 内容工厂（Content Factory）

一人快速产出高质量商品内容，覆盖多平台。

#### 3.1 商品标题优化

**输入**：产品名称 + 核心卖点 + 目标平台

**各平台标题规则**：

| 平台 | 字数限制 | 标题结构 | 示例模板 |
|-----|---------|---------|---------|
| 淘宝 | ≤30字(60字符) | 核心词 + 属性词 + 修饰词 + 长尾词 | [品牌]品类词+材质+功能+场景+风格 |
| 抖音 | ≤30字 | 痛点/场景 + 利益点 + 情绪词 | "再也不用担心XX！这个XX让你XX" |
| 小红书 | ≤20字 | 痛点 + 解决方案 + 使用场景 | "XX党必入！XX场景下的XX神器" |
| 拼多多 | ≤30字 | 核心词堆叠 + 价格暗示 | "XX批发XX元XX功能XX材质" |

**输出**：3个标题方案（按平台模板生成） + SEO关键词建议

#### 3.2 详情页/卖点评测

**输入**：产品信息 + 目标用户画像

**输出框架**（FAB法则）：
```
第一屏：痛点共鸣（目标用户的3个核心痛点）
第二屏：产品展示（核心卖点 + 使用场景图）
第三屏：功能详解（Feature → Advantage → Benefit 逐条展开）
第四屏：信任背书（材质认证/检测报告/销量数据/好评截图）
第五屏：规格参数（尺寸/材质/颜色/包装清单）
第六屏：服务承诺（发货/售后/退换货政策）
```

#### 3.3 短视频/直播脚本

**输入**：产品 + 平台 + 时长(15s/30s/60s)

**短视频脚本结构**：
```
[0-3s]  Hook钩子：制造悬念/抛出痛点/反常识
[3-10s] 痛点放大：展示用户真实痛点场景
[10-25s] 产品登场：展示产品 + 核心卖点演示
[25-40s] 信任背书：效果对比/用户评价/权威认证
[40-50s] 限时优惠：价格锚点 + 限时限量
[50-60s] CTA行动号召：点击链接/关注店铺/评论区互动
```

#### 3.4 多平台内容适配

**输入**：一篇内容（标题/正文/卖点）+ 目标平台

**输出**：自动改写适配不同平台风格
- 淘宝版：信息密度高、关键词密集（核心关键词靠前放置）
- 抖音版：口语化、情绪化、短句（多用感叹号，突出场景和利益点）
- 小红书版：种草风、emoji丰富、个人体验感（第一人称视角）
- 拼多多版：简洁、突出性价比（堆叠核心关键词，突出价格优势）

#### 3.5 广告法合规检查（嵌入内容生成流程）

**每次生成内容时自动执行**：

**违禁词库**（基于《广告法》第九条，支持从 JSON 文件自定义加载）：

| 类别 | 违禁词示例 | 替换建议 |
|-----|-----------|---------|
| 绝对化用语 | 最、第一、唯一、首个、最佳、极品、顶级 | 热销、优选、人气之选 |
| 权威性误导 | 国家级、世界级、全网首发 | 品牌自研、匠心打造 |
| 虚假承诺 | 100%有效、永久、包治、绝对 | 持久、显著、长效 |
| 夸大功效 | 速效、神效、奇效、立竿见影 | 明显改善、有效提升 |
| 伪科学 | 科学证明、医学认证（无证时） | 实验室测试、用户实测反馈 |
| 诱导消费 | 马上抢、仅剩X件、不买后悔 | 限时优惠、库存有限 |

**法律依据**：
- 《中华人民共和国广告法》第九条：广告不得使用"国家级""最高级""最佳"等用语
- 《中华人民共和国广告法》第十一条：广告使用数据、统计资料等应当真实、准确
- 《中华人民共和国广告法》第二十八条：广告以虚假或者引人误解的内容欺骗、误导消费者的，构成虚假广告

**检查流程**：
1. 生成内容后逐词扫描违禁词库
2. 发现违禁词 → 标红 + 给出替换建议
3. 检查功效宣称是否有依据
4. 检查价格标注是否合规
5. 输出合规审查结果 + 修改后版本

### 4. 智能客服（Service Bot）

一人公司7×24客服的"话术大脑"。

#### 4.1 售前咨询话术库

| 场景 | 回复策略 | 话术模板 |
|-----|---------|---------|
| 问尺寸/规格 | 引导提供信息 → 精准推荐 | "亲，为了给您推荐最合适的尺码，方便告诉我您的身高体重和平时穿的尺码吗？" |
| 问真假/正品 | 品牌授权链 + 正品承诺 | "我们是[品牌]官方授权店铺，每件商品都有防伪码，您可以拨打[品牌官方电话]验证真伪。" |
| 问优惠/砍价 | **多轮阶梯话术** | 第1轮：满减+会员折扣引导；第2轮：赠品补偿；第3轮：品质价值强调 |
| 问发货/物流 | 时效承诺 + 查询引导 | "下单后[X]小时内发货，一般[X]天左右到达，您可以在订单详情页实时查看物流信息。" |
| 问退换货 | 七日无理由说明 | "支持七日无理由退货，收到商品7天内不影响二次销售都可以退换，运费由我们承担。" |

> 💡 **多轮追问**：砍价场景内置 3 轮递进话术，从满减引导→赠品补偿→品质强调，逐步化解价格异议。

#### 4.2 售后处理决策树

```
客户问题分类
│
├── 质量问题
│   → 第一步：诚恳道歉，安抚情绪
│   → 第二步：引导举证（拍照/视频展示问题）
│   → 第三步：根据严重程度选择方案
│       ├── 轻微瑕疵 → 补偿（优惠券/部分退款）
│       ├── 影响使用 → 补发/换货
│       └── 严重问题 → 全额退款 + 运费承担
│
├── 物流问题
│   → 查单确认物流状态
│   ├── 未发货 → 催促发货 + 赔偿方案
│   ├── 运输中延误 → 联系快递催件 + 预计到达时间
│   └── 丢件/破损 → 联系快递索赔 + 补发或退款
│
├── 不满意/不喜欢
│   → 引导七日无理由退货
│   → 确认商品完好（未使用/未拆封/不影响二次销售）
│   → 说明退货流程和运费承担
│
├── 差评处理
│   → 分析差评原因
│   │   ├── 产品问题 → 认领 + 改进方案 + 补偿
│   │   ├── 服务问题 → 道歉 + 改进承诺
│   │   ├── 物流问题 → 解释 + 改进
│   │   └── 恶意差评 → 客观回复 + 平台申诉 + 证据保全
│
└── 大额纠纷（金额>500元或涉及投诉）
    → 保留完整聊天记录和交易快照
    → 优先协商解决
    → 协商不成 → 引导平台介入
    → 平台处理不满意 → 法律途径（消费者协会/12315/诉讼）
```

#### 4.3 退换货合规处理

**七日无理由退货规则**：

| 项目 | 规则 | 法律依据 |
|-----|------|---------|
| 适用范围 | 通过网络方式购买的商品 | 《消费者权益保护法》第二十五条 |
| 退货期限 | 收到商品之日起7日内 | 同上 |
| 运费承担 | 一般由消费者承担（双方另有约定除外） | 同上 |
| 商品要求 | 不影响二次销售 | 同上 |
| 拆封查验 | 因检查商品必要拆封且不影响完好的，不得拒绝退货 | 最高法司法解释 |

**不适用七日无理由退货的商品**（《消费者权益保护法》第二十五条）：
- 定作的商品
- 鲜活易腐的商品
- 在线下载或者消费者拆封的音像制品、计算机软件等数字化商品
- 交付的报纸、期刊

#### 4.4 差评回复模板库

| 差评类型 | 回复策略 | 模板 |
|---------|---------|------|
| 产品质量 | 认领+改进+补偿 | "非常抱歉给您带来不好的体验！我们已经反馈给品控部门，问题已定位在[具体原因]，已改进。为表歉意，为您申请了[X]元补偿/优惠券，希望您再给我们一次机会。" |
| 物流问题 | 解释+改进 | "很抱歉物流让您久等了！经查您的包裹因[原因]导致延误，我们已联系快递加强管理。下次下单我们会优先为您选择更快的物流方式。" |
| 不合理差评 | 客观陈述 | "感谢您的反馈。关于您提到的问题，实际情况是[客观说明]。我们已主动联系您沟通解决方案，如有任何疑问欢迎随时联系客服。" |

#### 4.5 平台规则变更提醒

内置近期平台规则变更摘要，帮助一人公司及时了解政策变化：

| 平台 | 变更内容 | 影响 |
|-----|---------|------|
| 抖音 | 珠宝类目佣金调整为5%-10% | 定价需重新计算扣点 |
| 小红书 | 个人店限制每日发布商品数量 | 新品上架节奏需调整 |
| 拼多多 | 百亿补贴门槛调整，需提供近30天销量数据 | 报名条件变化 |
| 淘宝 | 商品标题新增违规词自动检测机制 | 标题需更加注意合规 |

### 5. 电商合规检查（Legal Guard）

一人电商最容易踩的合规红线，一次性扫雷。

**检查维度**：

| 检查项 | 法律依据 | 常见违规表现 | 风险等级 |
|-------|---------|------------|---------|
| 广告违禁词 | 《广告法》第9条 | "最""第一""100%有效""国家级" | 🔴 高 |
| 虚假宣传 | 《广告法》第28条 | 捏造功效、虚构评价、假销量 | 🔴 高 |
| 虚假原价/价格欺诈 | 《价格法》第14条 | 原价无真实交易记录、虚假折扣 | 🔴 高 |
| 虚假评价/刷单 | 《反不正当竞争法》第8条 | 刷单炒信、好评返现、虚构评价 | 🔴 高 |
| 七日无理由退货 | 《消保法》第25条 | 拒绝合理退货、设置不合理门槛 | 🟡 中 |
| 个人信息保护 | 《个人信息保护法》第13条 | 过度收集买家信息、未获同意 | 🟡 中 |
| 产品质量 | 《产品质量法》第12-13条 | 销售不合格/无3C认证产品 | 🔴 高 |
| 知识产权侵权 | 《商标法》第57条、《著作权法》 | 侵权商品、盗图、盗用品牌 | 🔴 高 |
| 虚假促销 | 《规范促销行为暂行规定》 | 先涨后降、虚假满减 | 🟡 中 |
| 格式条款 | 《消保法》第26条 | "最终解释权归本店所有"等霸王条款 | 🟡 中 |

**检查流程**：
1. 用户输入商品标题/详情页文案/促销活动描述
2. 逐项扫描违禁词库和合规规则
3. 标注违规项（红/黄/绿）
4. 给出修改建议和替换词
5. 引用具体法律条文

**违禁词库扩展**：支持从 JSON 文件加载自定义违禁词库，方便用户根据行业特点扩展。

**输出**：合规检查报告
- 违规项清单（红/黄标注）
- 每项附法律条文 + 修改建议
- 修改后的合规版本

### 6. 运营数据诊断（Analytics Dashboard）

帮一人电商看懂数据、找到优化方向。

**核心指标体系**（采用数值型精确比较）：

| 指标 | 计算公式 | 健康值 | 预警值 | 比较模式 | 优化方向 |
|-----|---------|-------|-------|---------|---------|
| 转化率 | 成交UV ÷ 浏览UV | ≥3% | <3% | 越高越好 | 优化标题/主图/价格 |
| 客单价 | 销售额 ÷ 订单数 | 视品类 | 环比↓>20% | 绝对值 | 搭配销售/满减活动 |
| 退款率 | 退款订单 ÷ 总订单 | ≤5% | >5% | 越低越好 | 检查产品质量/描述准确性 |
| 复购率 | 复购客户 ÷ 总客户 | ≥15% | <15% | 越高越好 | 会员体系/老客优惠 |
| ROI | 销售额 ÷ 推广费用 | ≥3 | <3 | 越高越好 | 优化投放/暂停低效渠道 |
| 好评率 | 好评数 ÷ 总评价数 | ≥95% | <95% | 越高越好 | 售后改进/差评跟进 |
| 客服响应时间 | 平均首次回复时长 | ≤30秒 | >30秒 | 越低越好 | 设置自动回复/快捷话术 |
| DSR评分 | 平台动态评分 | ≥4.7 | <4.7 | 越高越好 | 物流/服务/描述三维度逐一排查 |

**诊断报告输出**：
- 各指标当前值 + 健康评级（🟢/🟡/🔴）
- 针对异常指标给出具体优化建议
- 生成"今日待办清单"
