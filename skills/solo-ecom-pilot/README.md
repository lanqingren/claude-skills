## 🎯 适用场景

- 一个人做电商，不知道卖什么好
- 产品定了但不知道怎么定价才不亏本
- 一人写不完商品标题、详情页、短视频文案
- 客服咨询和售后处理忙不过来
- 担心广告法违禁词、价格欺诈等合规问题
- 有店铺数据但不知道怎么分析和优化

## ✨ 六大核心功能

### 1. 🔍 智能选品（MarketIntel）
帮一人电商做"卖什么"的决策，五维评分卡评估。

**两种分析模式**：
- **知识库查询**：内置 8 大热门品类（蓝牙耳机、手机壳、家居收纳、食品零食、美妆工具、宠物用品、数码配件、手工文创），输入品类名即刻获取评分
- **交互式问卷**：5 个关键问题，适用于知识库未覆盖的品类

| 维度 | 分析内容 | 一人公司特殊考量 |
|-----|---------|----------------|
| 市场容量 | 搜索热度、销量趋势 | — |
| 竞争强度 | 头部占比、新进入者 | — |
| 利润空间 | 品类均价、成本区间 | 毛利率>40%才适合一人 |
| 季节性 | 淡旺季分布 | 一人库存压力大，慎选季节品 |
| 供应链门槛 | 起订量、供货周期 | 优先轻资产（一件代发/按需生产） |

### 2. 💰 定价引擎（PricingEngine）
科学定价，内置 6 大平台 × 7 大类目扣点数据，自动计算利润。

```
总成本 = (采购+包装+物流) × (1 + 退货率)
建议售价 = 总成本 ÷ (1 - 平台扣点 - 营销预留 - 目标毛利率)
```

- **类目级精确扣点**：30+ 条平台×类目扣点数据，模糊匹配用户输入
- **用户自定义覆盖**：支持手动指定扣点
- 三档定价方案（保守/建议/激进）
- 利润模拟表（不同售价下的毛利/净利）
- **定价合规自动检查**（虚构原价、虚假折扣预警）
- **库存风险提示**（首单量/一件代发/资金警戒线）

### 3. ✍️ 内容工厂（ContentFactory）
一人快速产出多平台商品内容。

- **商品标题优化**：淘宝/抖音/小红书/拼多多各平台规则适配
- **详情页文案**：FAB法则结构化卖点
- **短视频脚本**：15s/30s/60s 三种时长模板
- **多平台改写**：一篇内容自动适配4种平台风格
- **广告法合规检查**：内置50+违禁词库，支持JSON自定义扩展，生成即检

### 4. 🎧 智能客服（ServiceBot）
一人公司的7×24客服话术大脑。

- **售前话术库**：5大高频场景（尺寸/正品/砍价/发货/退换）
- **多轮追问预案**：砍价场景内置3轮递进话术（满减引导→赠品补偿→品质强调）
- **售后决策树**：质量问题/物流问题/不满意/差评 四类处理流程
- **差评回复模板**：产品质量/物流/不合理 三类回复策略
- **退换货合规**：七日无理由退货规则 + 例外清单
- **平台规则提醒**：近期平台规则变更摘要

### 5. ⚖️ 电商合规检查（AdComplianceChecker）
10大合规红线一次性扫雷。

| 检查项 | 法律依据 | 风险 |
|-------|---------|-----|
| 广告违禁词 | 《广告法》第9条 | 🔴 |
| 虚假宣传 | 《广告法》第28条 | 🔴 |
| 虚假原价 | 《价格法》第14条 | 🔴 |
| 刷单炒信 | 《反不正当竞争法》第8条 | 🔴 |
| 七日无理由退货 | 《消保法》第25条 | 🟡 |
| 个人信息保护 | 《个人信息保护法》第13条 | 🟡 |
| 产品质量 | 《产品质量法》第12-13条 | 🔴 |
| 知识产权侵权 | 《商标法》第57条 | 🔴 |
| 虚假促销 | 《规范促销行为暂行规定》 | 🟡 |
| 霸王条款 | 《消保法》第26条 | 🟡 |

### 6. 📊 运营数据诊断（AnalyticsDashboard）
8大核心指标健康检查 + 优化建议。

| 指标 | 健康值 | 比较模式 |
|-----|-------|---------|
| 转化率 | ≥3% | 越高越好 |
| 客单价 | 视品类 | 绝对值 |
| 退款率 | ≤5% | 越低越好 |
| 复购率 | ≥15% | 越高越好 |
| ROI | ≥3 | 越高越好 |
| 好评率 | ≥95% | 越高越好 |
| 客服响应时间 | ≤30秒 | 越低越好 |
| DSR评分 | ≥4.7 | 越高越好 |

> 💡 v1.1.0 采用**数值型精确比较**替代字符串匹配，诊断结果更准确。

## 🛠️ 技术实现

```
solo-ecom-pilot/
├── SKILL.md          # Skill配置文件（YAML frontmatter + Markdown）
├── README.md         # 平台展示文档
└── scripts/
    └── main.py       # 核心引擎实现（v1.1.0）
```

### 核心类架构

```python
MarketIntel            # 智能选品引擎
├── resolve_category()              # 模糊品类匹配（别名映射）
├── analyze_from_kb()               # 知识库查询（8大品类）
├── analyze_from_questionnaire()    # 交互式问卷分析
└── generate_selection_report()     # 选品报告（★星级展示）

ContentFactory         # 内容工厂
├── generate_titles()              # 商品标题（4平台×3模板）
├── generate_detail_page()          # 详情页文案（FAB法则）
├── generate_video_script()         # 短视频脚本（15s/30s/60s）
└── adapt_content()                 # 多平台内容适配

PricingEngine          # 定价引擎
├── _get_platform_rate()            # 类目级扣点查询（30+条数据）
├── calculate_price()               # 三档定价计算
└── generate_pricing_report()       # 定价报告生成

AdComplianceChecker    # 广告法合规检查
├── __init__(wordlist_path=None)    # 支持JSON自定义词库
├── check_text()                    # 违禁词扫描
└── generate_compliance_report()    # 合规报告

ServiceBot             # 智能客服
├── get_pre_sale_response()         # 售前话术（支持多轮追问）
├── get_after_sale_guide()          # 售后决策树
└── get_platform_rules_summary()    # 平台规则变更摘要

AnalyticsDashboard     # 数据诊断
└── diagnose()                    # 数值型指标健康检查
```
