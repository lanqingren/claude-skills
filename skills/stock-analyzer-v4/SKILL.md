# Stock Analyzer V4 - A股股票分析工具

A股股票分析增强版，提供全方位的股票数据分析。

## 功能特性

| 模块 | 分析内容 |
|------|----------|
| 实时行情 | 当前价格、涨跌幅、最高价、最低价、开盘价 |
| 量能指标 | 成交量、成交额、换手率、市值 |
| 估值指标 | 动态市盈率(PE)、市净率(PB) |
| 技术分析 | MA均线系统、MACD、RSI |
| 公司基本面 | 公司概况、主营业务、股本信息 |
| 行业分析 | 行业识别、政策环境、趋势研判 |
| 资金流向 | 主力净流入/流出、超大单/大单/中单/小单分布 |
| 主要股东 | 前5大股东持仓情况 |
| 投资建议 | 综合评分、短线操作、中线配置、长线持有 |

## 使用方法

### 分析单只股票

```bash
python3 scripts/stock_analyzer_v4.py <股票代码>
```

示例：
```bash
python3 scripts/stock_analyzer_v4.py 600519    # 分析贵州茅台
python3 scripts/stock_analyzer_v4.py 000001    # 分析平安银行
python3 scripts/stock_analyzer_v4.py 688256    # 分析寒武纪
```

### 快速扫描多只股票

```bash
python3 scripts/stock_monitor_fast.py [股票列表文件]
```

示例：
```bash
python3 scripts/stock_monitor_fast.py /path/to/stock_list.txt
```

## 数据源

- **腾讯财经**（主数据源）
- **新浪财经**（备用）
- **东方财富**（备用）
- **akshare**（财务数据、股东数据）

多数据源自动切换，确保数据获取成功率。

## 技术栈

- Python 3.8+
- requests（HTTP请求）
- akshare（财经数据接口）
- pandas（数据分析）

## 安装依赖

```bash
pip install requests akshare pandas
```
