# Thesis Architect v4.0

> 不是导师，是建筑师——你给方向，我搭框架，你填空。

---

## 这是什么？

一个帮助用户快速搭建论文框架、生成初稿结构、加工素材的 AI 技能。

**与 thesis-tutor v3.4 的区别**：

| 维度 | v3.4 (tutor) | v4.0 (architect) |
|------|--------------|------------------|
| 定位 | 导师——教你写 | 建筑师——帮你搭 |
| 交互 | 7阶段逐步引导 | 1-2轮输出框架 |
| 输出 | 建议和检查清单 | 可直接用的文稿 |
| 用户负担 | 需要主动思考 | 只需确认和填充 |

---

## 核心功能

### ① 快速起题
```
输入：专业 + 方向 + 年级
输出：3-5个选题建议 + 可行性评估
轮次：1-2轮对话
```

### ② 大纲生成
```
输入：选题 + 字数要求
输出：完整大纲（到三级标题）+ Word导出
轮次：1轮确认
```

### ③ 章节扩写
```
输入：章节标题 + 用户材料
输出：该章节初稿
轮次：按需调用
```

### ④ 材料加工
```
输入：文献/数据/访谈记录
输出：整理后的可用内容
轮次：按需调用
```

## 使用示例

**场景一：快速起题**
```
用户：我学市场营销，本科，想写品牌相关
AI：给你3个选题方向：
    1. 新媒体时代品牌忠诚度影响因素研究
    2. 国货品牌年轻化营销策略研究
    3. 品牌联名对消费者购买意愿的影响研究
    [附可行性和研究方法建议]
    
    选哪个？
```

**场景二：大纲生成**
```
用户：选第2个，国货品牌年轻化，8000字
AI：[生成完整大纲]
    第一章 绪论（1000字）
      1.1 研究背景
      1.2 研究目的与意义
      ...
    确认后导出Word模板？
```

**场景三：章节扩写**
```
用户：[丢了一段访谈记录] 帮我写案例分析那章
AI：[整理材料，生成案例描述+分析框架]
```

## 设计理念

1. **输出优先** — 用户要的是文稿，不是方法论
2. **最少交互** — 能一轮解决的不要两轮
3. **可编辑性** — 生成的都是草稿，用户可以改
4. **承认边界** — 这是协作工具，不是代写器

---

## 不做的事

- ❌ 不一键生成完整可交的论文
- ❌ 不编造文献或伪造数据
- ❌ 不承诺查重率
- ❌ 不替用户做研究
