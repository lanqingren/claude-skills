# 文献综述模板

> 适用于：以文献综述为主要研究方法的论文

---

## 研究流程

```
确定主题 → 文献检索 → 筛选评估 → 阅读提取 → 分析综合 → 撰写
```

---

## 文献综述类型

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| 叙述性综述 | 定性总结 | 研究现状梳理 |
| 系统综述 | 系统方法 | 临床/干预研究 |
| 元分析 | 定量整合 | 效果量整合 |
| 范围综述 | 绘图式 | 新兴领域探索 |

---

## 第二章 文献综述结构

```markdown
## 第二章 文献综述
### 2.1 核心概念界定
- 概念演变
- 概念辨析
- 本研究定义

### 2.2 理论基础
- 理论一：发展脉络+核心观点
- 理论二：发展脉络+核心观点
- 理论整合

### 2.3 {研究主题一}研究综述
- 国外研究
- 国内研究
- 研究进展

### 2.4 {研究主题二}研究综述
- 国外研究
- 国内研究
- 研究进展

### 2.5 研究述评与空白识别
- 已有研究贡献
- 现有研究不足
- 研究空白
- 本研究定位
```

## 文献检索策略

### 数据库选择
| 学科 | 常用数据库 |
|------|-----------|
| 综合 | Web of Science, Scopus, Google Scholar |
| 中文 | CNKI, 万方, 维普 |
| 经管 | EBSCO, EconLit |
| 教育 | ERIC, PsycINFO |
| 医学 | PubMed, Cochrane |
| 计算机 | IEEE, ACM |

### 检索式示例
```
主题: (品牌忠诚 OR brand loyalty) 
AND (影响因素 OR determinants OR factors)
时间: 2015-2025
文献类型: 期刊论文
```

## 综述写作技巧

### 组织方式

**按时间顺序**
```
早期研究 → 中期发展 → 近期进展
```

**按主题组织**
```
主题一 → 主题二 → 主题三
```

**按方法论组织**
```
量化研究 → 质性研究 → 混合研究
```

**按学派/观点组织**
```
观点A → 观点B → 观点对比
```

### 过渡句示例
```
- 针对上述问题，XXX提出了...
- 与XXX不同，XXX认为...
- 近年来，学者们开始关注...
- 综上，已有研究在...方面取得了进展，但在...方面仍有不足
```

## 文献引用规范

### 引用原则
- 重要文献必引
- 近5年文献占比≥40%
- 外文文献占比建议≥30%
- 避免过度自引

### 常见格式
| 格式 | 适用学科 |
|------|---------|
| APA | 心理学、教育学、商科 |
| MLA | 人文学科 |
| Chicago | 历史、艺术 |
| GB/T 7714 | 中文通用 |
