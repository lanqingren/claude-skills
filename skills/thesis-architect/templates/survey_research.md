# 问卷研究模板

> 适用于：采用问卷调查方法的量化研究

---

## 研究流程

```
确定研究问题 → 文献回顾 → 提出假设 → 问卷设计 → 预测试 → 正式调查 → 数据分析 → 结论
```

---

## 第三章 研究设计结构

```markdown
## 第三章 研究设计与方法
### 3.1 研究模型构建
- 理论模型
- 研究假设

### 3.2 变量测量
- 自变量测量
- 因变量测量
- 中介/调节变量测量
- 控制变量

### 3.3 问卷设计

- 描述性统计
- 信效度检验
- 假设检验方法
```

## 常用量表示例

### 态度/感知类（Likert 5点或7点）
```
1 = 非常不同意
2 = 不同意
3 = 一般
4 = 同意
5 = 非常同意
```

### 行为频率类
```
1 = 从不
2 = 很少
3 = 有时
4 = 经常
5 = 总是
```

### 满意度类
```
1 = 非常不满意
...
5 = 非常满意
```

## 样本量建议

| 分析方法 | 最低样本量 | 建议样本量 |
|---------|-----------|-----------|
| 描述统计 | 30 | 100+ |
| 相关分析 | 50 | 150+ |
| 回归分析 | 自变量数×10 | 200+ |
| 结构方程 | 200 | 300+ |
| 多组比较 | 每组≥50 | 每组100+ |

## 问卷设计检查清单

- [ ] 题目表述清晰无歧义
- [ ] 避免双重否定
- [ ] 避免诱导性问题

- [ ] 反向题设置
- [ ] 人口统计学变量完整
- [ ] 预测试已完成
- [ ] 信效度达标（α>0.7）
