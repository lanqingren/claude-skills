# 本科文科论文通用模板

> 适用于：文学、历史、哲学、社会学、教育学、管理学、经济学、法学等文科类专业

---

## 标准结构（8000-15000字）

```markdown
# {论文标题}

## 摘要（300-500字）
- 研究背景（1-2句）
- 研究目的（1句）
- 研究方法（1句）
- 主要发现（2-3句）
- 研究意义（1句）
【关键词】：3-5个

## 第一章 绪论（1000-2000字）
### 1.1 研究背景
- 宏观背景：行业发展/社会现象/政策环境
- 微观背景：具体问题/现象描述
- 研究必要性

### 1.2 研究目的与意义
- 研究目的（要解决什么问题）
- 理论意义
- 实践意义

### 1.3 国内外研究现状
- 国外研究综述
- 国内研究综述
- 研究述评（现有研究不足）

### 1.4 研究内容与方法
- 研究内容概述
- 研究方法说明

### 1.5 论文结构安排
- 各章内容概要

## 第二章 理论基础/文献综述（1500-3000字）
### 2.1 核心概念界定
- 关键概念1
- 关键概念2
- 概念关系

### 2.2 理论基础
- 理论一：概述+应用
- 理论二：概述+应用
- 理论对本研究的指导

### 2.3 文献综述
- 按主题/时间线组织
- 文献对比分析

## 第三章 研究设计/方法（1000-2000字）
### 3.1 研究对象
- 研究对象描述
- 样本选择标准

### 3.2 研究方法
- 主要研究方法
- 方法选择理由

### 3.3 数据收集与分析方法
- 数据来源
- 收集工具（问卷/访谈提纲等）
- 分析方法

## 第四章 研究结果/案例分析（3000-6000字）
### 4.1 {根据研究内容命名}
- 描述性分析
- 主要发现

### 4.2 {根据研究内容命名}
- 深入分析
- 对比发现

### 4.3 {根据研究内容命名}
- 核心论证
- 验证结论

## 第五章 结论与建议（1000-2000字）
### 5.1 研究结论
- 主要发现总结
- 研究假设验证结果

### 5.2 研究局限
- 样本局限
- 方法局限
- 时间/资源局限

### 5.3 建议
- 实践建议
- 后续研究建议

## 参考文献
[按学校要求格式排列，一般不少于15篇]

## 附录（如有）
- 问卷
- 访谈提纲
- 数据表格
```

---

## 字数分配建议

| 章节 | 8000字 | 10000字 | 15000字 |
|------|--------|---------|---------|
| 摘要 | 300 | 400 | 500 |
| 第一章 | 1000 | 1500 | 2000 |
| 第二章 | 1500 | 2000 | 3000 |
| 第三章 | 1000 | 1500 | 2000 |
| 第四章 | 3000 | 4000 | 6000 |
| 第五章 | 1000 | 1000 | 1500 |

---

## 常见研究方法适配

### 文献研究型
```
第三章 → 文献来源与分析框架
第四章 → 文献分析结果
```

### 问卷调查型
```
第三章 → 问卷设计+样本选择
第四章 → 数据分析+假设检验
```

### 案例研究型
```
第三章 → 案例选择+分析框架
第四章 → 案例描述+案例分析
```

### 访谈研究型
```
第三章 → 访谈对象+访谈设计
第四章 → 访谈资料编码+主题分析
```

---

## 学科特殊要求

### 经济学
- 第二章增加"模型设定"
- 第四章增加"实证结果"

### 管理学
- 可增加"案例分析"专章
- 注重实践建议

### 教育学
- 注重教育实践指导
- 可增加教学设计

### 法学
- 增加法律条文分析
- 注重案例援引

### 社会学
- 注重方法论述
- 数据呈现规范
