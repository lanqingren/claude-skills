# 实验研究模板

> 适用于：采用实验方法的自然科学、心理学、教育学等研究

---

## 研究流程

```
提出假设 → 实验设计 → 变量操作化 → 实验实施 → 数据收集 → 统计分析 → 结论
```

---

## 实验设计类型

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| 前后测设计 | 无对照组 | 初步探索 |
| 对照组设计 | 有对照组 | 因果推断 |
| 准实验设计 | 无随机分配 | 现场/教育研究 |
| 真实验设计 | 随机分配 | 实验室研究 |
| 因子设计 | 多变量操控 | 交互效应研究 |

## 常用统计方法

| 实验设计 | 统计方法 |
|---------|---------|
| 两组前后测 | 配对t检验 |
| 两组对照 | 独立样本t检验 |
| 多组对照 | 单因素方差分析 |
| 因子设计 | 多因素方差分析 |
| 含协变量 | 协方差分析 |
| 重复测量 | 重复测量方差分析 |

## 样本量估算

### 常用指标
- 显著性水平（α）：通常0.05
- 统计功效（1-β）：通常0.80
- 效应量：小(0.2)/中(0.5)/大(0.8)

### 估算方法
```
G*Power 软件估算
R: pwr包
Python: statsmodels.stats.power
```

## 常见问题

| 问题 | 解决方案 |
|------|---------|
| 样本量不足 | 提前估算，招募足够被试 |
| 操控失效 | 操控检验，调整材料 |
| 混淆变量 | 控制、随机化、平衡 |
| 需求效应 | 双盲设计、掩盖真实目的 |
| 外部效度低 | 多实验、现场实验验证 |
