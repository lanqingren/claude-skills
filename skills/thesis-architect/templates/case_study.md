# 案例研究模板

> 适用于：采用案例研究方法的质性研究

---

## 研究流程

```
确定研究问题 → 案例选择 → 数据收集（多源） → 数据分析 → 理论构建
```

---

## 案例研究类型

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| 单案例 | 深度挖掘 | 极端案例、典型案例 |
| 多案例 | 对比验证 | 理论构建、模式发现 |
| 探索性 | 发现新规律 | 研究较少的领域 |
| 描述性 | 完整描述 | 复杂现象记录 |
| 解释性 | 因果解释 | 因果机制研究 |

---

## 第三章 研究设计结构

```markdown
## 第三章 研究设计与方法
### 3.1 研究方法论选择
- 案例研究适用性论证
- 研究类型选择

### 3.2 案例选择
- 选择标准
- 案例描述
- 案例代表性说明

### 3.3 数据收集
- 数据来源（访谈/文档/观察/实物）
- 收集过程
- 数据三角验证

### 3.4 数据分析方法
- 编码方法
- 分析框架
- 软件工具（NVivo/Atlas.ti）
```

---

## 第四章 案例分析结构

### 单案例

```markdown
## 第四章 案例分析
### 4.1 案例背景
- 案例介绍
- 研究焦点

### 4.2 案例描述
- 时间线/发展阶段
- 关键事件
- 主要行动者

### 4.3 案例分析
- 分析框架一
- 分析框架二
- 模式发现

### 4.4 理论提炼
- 发现的理论命题
- 与已有理论对话
```

### 多案例

```markdown
## 第四章 案例分析
### 4.1 案例一分析
- 案例描述
- 案例分析

### 4.2 案例二分析
- 案例描述
- 案例分析

### 4.3 跨案例分析
- 相似模式
- 差异模式
- 模式解释

### 4.4 理论构建
- 理论命题
- 理论模型
```

## 访谈设计

### 半结构化访谈提纲示例
```
一、开场
- 自我介绍
- 研究目的说明
- 保密承诺

二、背景信息
- 您在公司的职位和工作年限
- 您在项目中的角色

三、核心问题
1. {开放式问题1}
   - 追问：能否举个具体例子？
   
2. {开放式问题2}
   - 追问：为什么会这样？
   
3. {开放式问题3}

四、补充问题
- 还有什么想补充的吗？
- 有没有我遗漏的重要方面？

五、结束
- 感谢访谈
- 后续联系说明
```

## 数据分析步骤

```
原始数据（访谈录音/文档）
    ↓
转录（逐字稿）
    ↓
一级编码（开放编码）
    ↓
二级编码（主轴编码）
    ↓
三级编码（选择性编码）
    ↓
理论模型
```

---

## 质量控制

### 信度
- 编码者间一致性检验
- 编码手册

### 效度
- 三角验证（数据/方法/研究者）
- 厚描述
- 成员检验（被访者确认）
- 外部审查

---

## 常见问题

| 问题 | 解决方案 |
|------|---------|
| 样本代表性 | 说明案例选择逻辑，不追求统计推广 |
| 主观性 | 多源数据验证、多人编码 |
| 信效度 | 编码者一致性、三角验证 |
| 结论推广 | 理论推广而非统计推广 |
