# 高考志愿填报助手

## 概述

基于"位次法"的高考志愿填报智能助手。核心理念：**看排名（位次）比看分数更重要** — 分数因试题难度波动，但考生的全省排名相对稳定。

本 Skill 提供位次查询、院校录取数据对比、冲稳保方案生成、专业选择建议等功能。


## 🚀 快速上手

### 信息收集（8维度全流程）

启动后按顺序收集以下信息。**前3项为必填**（缺失则暂停），第4-8项为推荐收集（缺失时说明默认假设后继续）：

| # | 信息项 | 必填 | 示例 | 缺失时的处理 |
|---|--------|------|------|-------------|
| 1 | **省份 + 高考模式 + 选科** | ✅必填 | 贵州省 / 3+1+2 / 物化政 | 暂停分析，友好询问 |
| 2 | **高考总分 + 全省位次** | ✅必填 | 536分 / 位次30139 | 暂停分析，友好询问 |
| 3 | **科类**（物理类/历史类/文/理科） | ✅必填 | 物理类 | 暂停分析，友好询问 |
| 4 | **意向地域** + 是否接受偏远 | 🉑推荐 | 不限 / 优先一线 | 默认=不限 |
| 5 | **家庭经济条件** + 费用偏好 | 🉑推荐 | 中等 / 不排斥中外合作 | 默认=中等，仅推公办 |
| 6 | **兴趣特长** + 明确排斥的专业/行业 | 🉑推荐 | 喜欢计算机 / 不想学医 | 默认=不限方向 |
| 7 | **发展诉求**（好就业/考研/考公/院校档次） | 🉑推荐 | 优先好就业+兼顾考研 | 默认=综合推荐 |
| 8 | **特殊身份**（艺术/体育/军校/专项/民族等） | 🉑推荐 | 无 | 默认=无 |

> 💡 **最佳输入格式**（用户只需像聊天一样说）：
> - "贵州省物理类536分，位次30139，选科物化政，想去江浙沪，家庭中等，想学计算机好就业"
> - "河南理科520分能上什么学校"

### Agent 收到后的标准流程（9步全流程）

```
1. 校验输入（8维度信息收集）→ 必填缺失则暂停询问，非必填缺失说明默认值
2. 判断省份高考模式（3+1+2/3+3/老高考）→ 查 references/national-policy-reference.md
3. 查内置数据 → 有则直接匹配，无则提示获取方式
4. ⭐ 询问招生计划变化（2026 vs 2025）→ 有数据则做位次调整
5. 按省份波动性选阈值 → 稳定/中等/高波动 三档自适应

9. 输出完整六板块 HTML 报告（基于 templates/report-template.html 模板） + 数据来源标注 + 风险提醒 + 费用参考
```


## 什么时候用

- 查询分数对应的全省位次（"550分在全省排多少名"）
- 根据位次筛选目标院校（"全省前30000名能上哪些211"）
- 查询目标院校往年录取位次（"华科计算机去年录取位次是多少"）
- 生成冲稳保志愿方案（"帮我设计一套冲稳保方案"）
- 院校/专业对比（"计算机和电子信息哪个更好"）
- 新高考选科对应专业（"物理+化学+生物能报哪些专业"）

**不做：** 预测当年精确录取分数线、替用户做最终决策、提供非官方数据源的数据。

## 核心方法论：位次法 + 招生计划调整

### 位次 vs 分数

| 维度 | 分数 | 位次（排名） |
|------|------|-------------|
| 稳定性 | 年波动大（试题难度影响） | 相对稳定 |
| 可比性 | 不同年份不可直接比 | 可直接对比 |
| 参考价值 | 辅助参考 | **核心参考坐标** |

### ⭐ 招生计划调整位次法（v2.9.0 新增）

**传统位次法的盲区**：只看排名，忽略了招生计划（供给侧）的变化。

当2026年某省本科招生总计划比2025年多20,000人时：
- **头部考生**（前1%）：985/211名额基本不变，影响**极小**（~300名差异）
- **中段考生**（前10-30%）：影响**中等**（~2,000-5,000名差异）
- **中后段考生**（前30-70%）：影响**关键**（~7,000-15,000名差异）
- **尾部考生**（前70-100%）：影响**巨大**（~15,000-20,000名差异）

#### 调整公式

**简化版**（仅需省级总计划数据）：

```
等效2025位次 = 2026实际位次 × (2025本科招生总计划 / 2026本科招生总计划)
```

> 示例：某省2025年本科计划200,000人，2026年220,000人（+10%）
> 考生2026年排100,000名 → 等效2025年位次 = 100,000 × (200,000/220,000) = 90,909名
> 即该考生在2026年的竞争力 ≈ 2025年的90,909名

**精确版**（需省级招生计划数据，**31省全覆盖**）：

使用全国供给曲线模型（`references/nationwide_enrollment_model.json`），按位次段做非线性调整：
1. 从供给曲线查到考生位次R对应的累计招生计划C(R)
2. 2026年等效计划 = C(R) × (2026总计划/2025总计划)
3. 从供给曲线反查：C⁻¹(等效计划) = 调整后位次

> 模型基于贵州2025年物理类专业级数据（129,668个名额，18,325条专业记录）构建供给曲线形状，再用各省2024年本科招生总计划+考生总数缩放到31省。各省曲线形状相同（头部名额集中、尾部稀疏），但绝对数量不同。

#### 使用方法

Agent 在生成2026年志愿方案时，**主动询问**用户：
> "2026年XX省本科招生总计划是多少？2025年是多少？（可从省考试院《招生计划》或新闻公告中获取）"

如果用户提供了招生计划数据：
1. 计算调整因子 = 2025计划 / 2026计划
2. 调整后位次 = 考生位次 × 调整因子
3. 用调整后位次匹配2025年院校录取位次
4. 在报告中展示"原始位次"和"调整后等效位次"两个数据

如果用户**未提供**招生计划数据：
1. 使用纯位次法（当前方法）
2. 提醒："建议查询XX省考试院2026年招生计划，如与2025年差异超过5%，可提供数据做精确调整"

#### 供给曲线原理

供给曲线描述的是「位次→累计可获取的招生名额」映射关系。核心特征：
- **头部极度集中**：前5%考生能获取30%+的名额
- **中段平缓过渡**：前30%约获取60%的名额
- **尾部极度稀疏**：前70%已获取85%+的名额，尾部15%考生争抢剩余15%

这一曲线形状在全国各省份高度一致（由高校层次结构决定），但各省绝对数量差异巨大。

> ⚠️ 以上数据基于贵州2025年物理类专业级实际数据（129,668名额/18,325条专业记录）构建曲线形状，再按各省2024年本科招生总计划+考生总数缩放。完整31省数据见 `references/nationwide_enrollment_model.json`

### 使用位次法的步骤

1. **查位次**：在考试院公布的《一分一段表》中，找到自己的高考总分对应的全省具体排名
2. **查校线**：查看目标院校近 3 年在本省的最低录取分数线
3. **比位次**：找到这些分数对应的历史排名位次
4. **定志愿**：
   - 🏃 **冲**：往年录取位次略高于自身位次（录取概率 40-60%）
   - ⚖️ **稳**：往年录取位次与自身位次相当（录取概率 70-85%）
   - 🛡️ **保**：往年录取位次低于自身位次（录取概率 90%+）

### 输出原则（用户偏好）

1. **多年份对比**：每个推荐必须显示**至少最近2年**的数据（如2024年位次+2023年位次），不要仅展示单一年份。标注数据年份供用户自行判断波动。
3. **数量充足**：每组（冲/稳/保）推荐至少**10所院校**，广东省可填45个专业组，太少推荐不实用。
4. **公办优先**：默认仅推荐公办院校（H9），稳妥志愿按学校质量排序——广州公办优先，985/211优先。
5. **推荐排序建议**：稳妥志愿不要仅按位次范围排序。建议用质量评分：985=100分，211=50分，广州市区=10分，其余0分。按质量分降序→最低位次升序排列。这样广工/广金（广州公办）排在嘉应/韶关（地级市公办）前面。
3. **位次范围展示**：每个学校展示其**专业组位次范围**（最低分专业组~最高分专业组），而非仅展示最低位次。同一学校不同专业组位次差异可能极大（如华南师范大学历史类从1,156到20,325）。

## 数据获取策略

### 官方数据源（优先级从高到低）

| 优先级 | 数据源 | 说明 |
|--------|--------|------|
| ⭐⭐⭐ | 省教育考试院官网 | 一分一段表、投档线、招生计划（最权威） |

| ⭐⭐ | 目标院校本科招生网 | 分省分专业录取数据 |
| ⭐⭐ | 阳光高考平台 | 院校信息、专业库 |
| ⭐ | 第三方聚合平台 | 掌上高考/夸克/百度AI助考等（仅供参考，以官方为准） |

### 数据获取工作流

```
用户输入分数/位次
    ↓
确定省份 + 科类（物理类/历史类/理科/文科）+ 选科（新高考）
    ↓
尝试从已缓存数据中匹配 → 无缓存则提示用户去官方渠道获取
    ↓
匹配目标院校往年录取数据
    ↓
按冲稳保三档生成方案
    ↓
输出志愿推荐表
```

## 常见陷阱

1. **只看分数不看位次** — 不同年份试题难度不同，分数不可直接对比
2. **忽略选科要求** — 新高考下选科直接决定能报哪些专业
3. **冲太多或保太多** — 合理分配是关键，别全冲或全保
4. **只看学校不看专业** — 好学校的冷门专业未必适合
5. **忽略招生章程** — 专业级差、单科要求、身体条件都可能退档
6. **不服从调剂** — 平行志愿下不服从调剂有退档风险
7. **只看去年数据** — 至少看 3 年数据，注意大小年现象
8. **推荐含民办院校未被用户要求** — 用户默认认为推荐的应是公办院校。必须在代码中显式过滤民办（`nature_name` 含 "民办" 的剔除），或用 `f985!=1 && f211!=1 && nature_name!="公办"` 判断。只有在用户明确说"民办也行"时才包含民办推荐。
9. **忽略招生计划变化** — 纯位次法假设两年间录取位次不变，但如果2026年本科招生计划大幅增加，同样位次的考生录取概率会提高。尤其对中后段考生（排位30%+），招生计划变化影响可达数千名位次差异。**生成方案时必须询问用户招生计划数据，有则用全国供给曲线模型（`references/nationwide_enrollment_model.json`）做调整——31省全覆盖**。


## FAQ 常见问题

### Q1：有分数但没有位次怎么办？
**A**：优先建议用户从省考试院查询位次（位次比分数准确得多）。如确无法获取：
1. 查内置一分一段表（`province_scores/`）反查位次
2. 若该省无一分一段表数据，用「分数模式」阈值（冲46%/稳58%/保93%），但需告知用户精度降低

### Q2：用户省份不在内置数据中怎么办？
**A**：明确告知"该省暂无内置投档数据"，然后：
1. 提供官方数据源链接（见 `references/data-sources.md`）
2. 用户可手动提供PDF/Excel，Agent 解析后生成方案
3. 部分省份可用相邻年份或相邻省份的阈值作为近似参考（需标注为估算）

### Q3：位次和分数模式有什么区别？该用哪个？
**A**：
- **位次模式**（推荐）：直接对比全省排名，更稳定。命中率：冲97.0%/稳90.0%/保95.2%（v28全国21省26组15,863对回测）
- **分数模式**：对比录取分数，波动更大。命中率：冲46%/稳58%/保93%
- **有位次数据时一律用位次模式**

### Q4：冲稳保命中率是什么意思？
**A**：指用上一年的录取数据来预测今年录取结果的准确性：
- 冲95.9% = 100个"冲刺"志愿中约96个今年仍在前方（有机会录取）
- 稳91.9% = "稳妥"志愿中约92个仍在合理区间
- 保96.0% = "保底"志愿中约96个确实低于考生位次
- ⚠️ 这是**跨年回测命中率**，不等于实际录取概率
- ✅ **v28已用3个年份对验证**：2022→2023冲100.0%/稳95.5%/保94.3%，2023→2024冲96.7%/稳89.2%/保94.8%，2024→2025冲97.7%/稳92.3%/保97.1%
- ✅ **2024→2025验证**（5省1,615对）：冲97.7%/稳92.3%/保97.1%
- ✅ **保底命中率稳定**：全国95.2%，各年份对94.3%~97.1%

### Q5：选科不对能不能报某个专业？
**A**：本 Skill 提供选科-专业覆盖率参考表，但**各校具体选科要求以招生章程为准**。Agent 应：
1. 查选科对照表给出初步判断
2. 明确提醒"请核实目标院校招生章程中的选科要求"
3. 不替用户做最终结论

### Q6：特殊招生类型（强基/综评/中外合作/国家专项）怎么处理？
**A**：见下方「特殊招生类型」章节。投档数据中含专项计划记录，Agent 会区分标注但需提醒额外资格条件。

### Q7：数据是哪一年的？会不会过时？
**A**：内置数据主要为2023-2025年。每年高考季后应更新。Agent 在输出报告时**必须标注数据年份**，并提醒"位次参考以最近一年为最重要"。

### Q8：不同省份的预测精度有差异吗？
**A**：有。基于v24回测和分科类回测（25省42组9,869对），关键发现：

| 省份类型 | 冲命中率 | 稳命中率 | 保命中率 | 建议 |
|---------|---------|---------|---------|------|
| 新高考3+3综合（上海/北京/浙江/天津/海南） | 96.6% | 89.3% | 90.1% | 保底略弱，建议增加1-2个保底志愿 |
| 新高考3+1+2物理（江苏/河北/湖南/湖北/重庆/贵州） | 96.8% | 88.5% | 94.3% | 冲稳保均衡，标准阈值适用 |
| 新高考3+1+2历史 | 96.1% | 88.8% | 96.1% | 保底可靠，冲刺略保守 |
| 老高考文科（山西/甘肃/陕西/黑龙江/广西等） | 95.7% | 84.9% | 98.2% | 稳命中率最低，建议冲稳保比例4:3:3 |
| 老高考理科 | 96.9% | 84.7% | 96.2% | 同上，稳命中率偏低需注意 |
| 高波动省份（云南/宁夏/新疆） | 93.5-97.3% | 87.4-90.6% | 92.1-96.4% | 冲稳保阈值均需适当放宽 |

**核心建议：**
- 🟢 新高考3+1+2省份：冲稳保最均衡，标准阈值适用
- 🟡 老高考省份（尤其文科/理科）：稳命中率偏低（~85%），建议冲稳保比例4:3:3多填冲刺
- 🟡 新高考3+3省份：保底命中率略低（90.1%），建议增加1-2个保底志愿
- 🟢 保底命中率全国平均95.2%，仍是最可靠的指标
- ⚠️ 老高考文科冲命中率95.7%全国最低，但保底98.2%最高——保底最稳

### Q9：为什么老高考文科冲命中率偏低？
**A**：回测发现老高考文科（山西55.5%、陕西51.7%、黑龙江52.5%）的冲命中率明显低于理科。可能原因：
1. **文科分数密集**：同分段人数多，1-2分差异可能导致位次跳变
2. **院校招生量少**：文科专业招生规模小，分数线波动更大
3. **调剂影响**：文科调剂空间小，部分考生被调剂到非首选专业

**应对策略**：老高考文科考生建议冲稳保比例为 **4:3:3**（多填一个冲的志愿）

### 广东历史类方案生成流程

当用户为广东历史类考生时，按以下步骤：

```
1. 解析2025年历史类一分一段表PDF（gd_extract_2025/文件1）
   → 用 pdfplumber 提取，正则匹配: r'^(\d{3})\s+(\d+)\s+(\d+)'
   → 得到 (分数, 人数, 累计人数) 列表
   → 注意区分"含本科加分"和"含专科加分"两列（本科列更关键）
   
2. 将用户分数换算为2025年排位：
   - 从表中找到用户分数对应的累计人数（本科含加分列）
   - 示例：2025年历史类529分→36,999名
   
3. **从multi_province/加载历史类真实投档数据（首选方案）：**
   - 加载 `~/.hermes/workspace/gaokao-data/multi_province/广东_2024_admission.json`
   - 用 `d.get('local_type_name')=='历史类'` 过滤历史类数据（~571条）
   - 解析 `min`（最低分）和 `min_section`（最低位次）字段
   - 也加载 `广东_2023_admission.json` 做多年份对比
   - **f985/f211处理**：f985==1 才是985（非布尔值），f211==1 才是211
   - 每个院校展示专业组位次范围（最低分专业组~最高分专业组）
   
4. 结合分数通胀校正（2024→2025广东历史类通胀约**+25分**）：
   - 529分在2024年排23,406名，2025年排36,999名
   - 跨年对比时必须用位次而非分数
   
5. **参考2025年各批次分数线做特殊通道分析**（来自省考试院公告）：
   - 特殊类型招生控制线：557分（强基/综评/高校专项）
   - 地方专项计划：527分 ✅ 用户529分超2分
   - 教师专项（华师/广州大学）：537分
   - 教师专项（其他院校）：487分
   - 卫生专项（本科）：537分
   - 本科线：464分
   
6. **过滤民办院校**：按 H9 默认仅推荐公办。
   - `nature_name` 含 "公办" 或 `f985==1` 或 `f211==1` 的保留
   - `nature_name` 含 "民办" 的直接剔除
   - 数据示例：广州南方学院 `nature_name="民办"` → 剔除
   
7. **生成冲稳保方案**，每档至少10所院校，标注2024+2023两年数据对比：
   - **冲刺（Rush）**：所有专业组位次均高于用户位次（`i["rx"] < u`）
   - **稳妥（Stable）**：用户位次落在院校专业组位次范围内（`i["rn"] < u <= i["rx"]`）
   - **保底（Safe）**：所有专业组位次均低于用户位次（`i["rn"] >= u`）
   - **稳妥排序建议**：按学校质量（985/211/广州市区优先）排序，而非仅按位次范围。打分公式示例：985=100分，211=50分，广州市区=10分，再按最低位次升序
```

## 输入校验与异常处理

### 必填信息校验

Agent 收到用户请求后，**必须先检查以下信息是否齐全**，缺失时主动友好询问：

| 检查项 | 必填 | 校验规则 | 缺失时的提示话术 |
|--------|------|---------|----------------|
| 省份 | ✅ | 31个省份名匹配（支持简称如"贵州"="贵州省"） | "请问是哪个省份的考生？" |
| 分数 | ✅ | 0-750整数，含政策加分 | "请问高考总分是多少（含加分）？" |
| 位次 | ⭐强烈推荐 | 正整数，与分数交叉验证 | "最好能提供全省位次，会更准确。可以从省考试院官网查到。" |
| 科类/选科 | ✅(新高考) | 物理/历史 或 具体3科 | "选科是什么组合？（如物化生）" |
| 科类 | ✅(老高考) | 文/理科 | "是文科还是理科？" |
| 招生计划变化 | 🉑推荐 | 2026 vs 2025本科招生总计划人数 | "建议从省考试院查询2026年本科招生计划。如与去年差异>5%，提供后可做精确位次调整。" |

### 自动校验逻辑

```
用户输入 → 提取关键信息
  ├─ 省份识别 ✅ → 判断新高考/老高考模式
  ├─ 分数范围 ✅ → 0-750，否则提示异常
  ├─ 位次交叉验证 → 有位次+分数时，用一分一段表验证是否匹配
  │   └─ 不匹配 → 提醒"您的分数和位次似乎不对应，请核实"
  ├─ 选科覆盖率 → 自动标注可报/受限专业
  └─ 数据可用性 → 检查内置数据是否覆盖该省
      ├─ 有数据 → 直接生成方案
      └─ 无数据 → 降级处理（见下方）
```

### 降级与容错策略

| 场景 | 降级策略 | 用户提示 |
|------|---------|---------|
| 无内置投档数据 | 使用相邻省份阈值近似 | "该省无直接数据，使用XX省参数近似估算，精度有限" |
| 有分数无位次 | 切换分数模式 | "使用分数模式估算，建议补充位次以提高准确度" |
| 数据年份单一 | 无法做大小年分析 | "仅有1年数据，无法判断大小年趋势，建议查阅近3年" |
| 分数接近批次线 | 保底比例增加 | "您的分数接近批次线，建议增加保底比例至5:3:2" |
| 高分段（全省前1%） | 位次极度密集 | "高分段位次竞争激烈，建议查阅具体院校专业组数据" |



## 特殊招生类型处理

| 类型 | Agent 行为 | 注意事项 |
|------|-----------|---------|
| **强基计划** | 提供基础信息，引导查阅阳光高考平台 | 有单独报名/校测流程，与普通批不冲突 |
| **综合评价** | 提供基础信息，提醒关注各校报名时间 | 各省/校政策差异大 |
| **中外合作办学** | 在推荐中标注"[中外合作]"，提示学费较高 | 投档数据中已区分 |
| **国家/地方专项** | 在推荐中标注"[专项]"，提醒需资格审核 | 仅限农村/贫困地区考生 |
| **民族班/预科** | 在推荐中标注"[民族/预科]"，提醒需民族身份 | 录取分数线通常低于普通类 |
| **艺术/体育类** | 使用工作流 F（综合分计算） | 各省综合分公式不同，需先确认 |
| **军校/警校** | 提醒需政审+体检+面试 | 政治科目是加分项（物化政选科优势） |

> **原则**：投档数据中的特殊类型记录会**自动区分标注**，不会混入普通类推荐。Agent 必须提醒用户核对自身是否具备相应资格条件。

## Windows 环境脚本执行注意事项

在 Windows PowerShell 环境下执行 Python 脚本时，注意以下坑：

### PowerShell 双引号转义问题

PowerShell 中通过 `cmd /c` 调用 Python 时，内层双引号的转义会导致解析失败（`MissingArgument`、`ParseException`）。**推荐方案：**

```
# 方法1：直接用 cmd.exe /c（避免 PowerShell 转义层）
cmd /c "D:\anaconda3\python.exe script.py arg1 arg2"

# 方法2：写 .py 文件后用 cmd 执行（避免任何转义）
# 先用 write_file 工具写脚本，再 cmd /c "python script.py"
```

### 中文编码问题（PS 5.1 核心坑）

PowerShell 5.1 的 here-string（`@""@` 和 `@''@`）和 `Out-File` 默认使用系统 ANSI 编码（中文 Windows = GBK），导致中文内容被错误转码为乱码（如 广东 → 骞夸笢）。**已验证的方案：**

```
# ✅ 方案1：在 PS 中构建字符串变量 + 管道传递给 Python
$G = [char]0x5E7F + [char]0x4E1C  # "广东" 用 unicode 码点
$code = @"
import json
print("$G")
"@
$code | D:\anaconda3\python.exe

# ✅ 方案2：用 .NET WriteAllText 指定 UTF8 无 BOM
$content = "Chinese text here"
[System.IO.File]::WriteAllText($path, $content, [System.Text.UTF8Encoding]::new($false))

# ❌ 方案3（不可用）：PowerShell python -c "..." 含中文 → 转义乱码
# ❌ 方案4（不可用）：PS @""@ heredoc 含中文管道到 Python → 转义乱码
```

> **关键原则**：PowerShell 本身不能正确处理含中文的 Python 代码。要么用 `[char]0xXXXX` 构建中文变量，要么用 Python 自己的文件写入（.py 文件），或在 cmd.exe 中运行。

### 文件写入方式

写 Python 脚本文件时，**不要用 PowerShell 的 `echo >>` 或 heredoc**（会导致编码/换行问题）。推荐：
- 使用 `write_file` 工具直接写入 `.py` 文件
- 或用 `[System.IO.File]::WriteAllText($path, $content, [System.Text.Encoding]::UTF8)`

### PDF 解析

广东数据 PDF 文件名因编码问题显示为乱码，但 `pdfplumber` 可正常读取内容。用 `extract_text()` 后正则匹配数据行即可。`pdfplumber` 依赖 `pypdfium2` 和 `pdfminer.six`，确保已安装。

### 数据目录路径

默认数据目录：`$env:USERPROFILE\\.hermes\\workspace\\gaokao-data\\`
可通过环境变量 `GAOKAO_DATA_DIR` 覆盖。
