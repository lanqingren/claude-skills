# 高考征集志愿（补录）数据源调研报告

> 调研日期：2026-07-02 | 调研人：Hermes Agent

---

## 1. 调研摘要

本报告对高考征集志愿（补录）数据的数据源进行了系统性调研，评估了主要数据源的可采集性、数据覆盖范围、格式一致性以及采集难度，并提出了分层采集策略建议。

**核心结论：**
1. **dxsbb.com（大学生必备网）** 是当前最可行的批量采集目标，HTML表格格式规整，覆盖全国31省多年份数据
2. **站内搜索功能已失效（返回404）**，需通过 sitemap 或分类页面间接发现 URL
3. **2023-2025年数据以HTML表格为主**，较早年份以图片形式存在（需OCR）
4. **各省考试院官网** 提供最权威数据，但格式不统一（PDF/HTML），采集成本高
5. **现有脚本 `fetch_supplement_admission.py` 已搭建框架**，但 DXSBB_SUPPLEMENT_PAGES 字典为空，需要填充实际URL
6. **数据目录 `supplement_data/` 目前为空**，未见已采集数据

## 2. 数据源详细评估

### 2.1 dxsbb.com（大学生必备网）⭐⭐⭐⭐⭐

| 项目 | 评估 |
|------|------|
| **URL模式** | 新闻页：`/news/{id}.html`；分类页：`/news/list_{id}.html` |
| **数据格式** | HTML `<table>` 表格 + 较早年份用图片 |
| **表结构** | 科类、院校代码、院校名称、计划数、投档数、投档最低分（6列） |
| **覆盖范围** | 全国31省，2015-2025年 |
| **可采集性** | ⭐⭐⭐⭐⭐ 最高，HTML表格无需登录，无验证码 |

#### 已验证的征集志愿页面示例

| URL | 标题 | 年份 | 省份 | 数据格式 |
|-----|------|------|------|---------|
| `/news/57494.html` | 2019年海南本科A批投档分数线（理科-征集志愿） | 2019 | 海南 | HTML表格（88条） |
| `/news/57491.html` | 2019年海南本科A批投档分数线（文科-征集志愿） | 2019 | 海南 | HTML表格 |
| `/news/list_595.html` | 2025年海南高考投档分数线汇总 | - | 海南 | 分类列表页 |
| `/news/list_1001.html` | 全国投档分数线查询汇总 | - | 全国 | 分类列表页（含山东第1/2/3次等） |

#### 发现策略

dxsbb.com 站内搜索返回404，但可通过以下方式发现URL：

1. **分类导航**：各省高考 → 投档分数 → 各年份列表
2. **sitemap.xml**：已验证可访问（`/sitemap.xml`），需验证完整URL列表
3. **页面内"上一篇/下一篇"**：页面底部提供相邻文章链接
4. **相关链接**：文章内的关键词链接（如`/news/list_200.html`=理工等）
5. **ID连续扫描**：从已知ID（如57491、57494）向上下扫描，根据标题关键词筛选

#### 数据格式示例

```
科类 | 院校代码 | 院校名称   | 计划数 | 投档数 | 投档最低分
理工 | 0102     | 中国民航大学 | 6     | 6     | 577
理工 | 0105     | 天津医科大学 | 1     | 1     | 721
```

#### 已知限制

- **较早年份（2019年及以前）** 的数据可能以图片形式存在，需要OCR
- **2025年最新数据** 可能还在持续更新中（8月才有最终数据）
- 部分页面可能混杂了非征集志愿的普通投档线数据，需通过标题关键词筛选

- PDF文件可能需要OCR识别
- 历史数据不易获取（部分省只保留当年数据）

### 2.3 中国教育在线 / 阳光高考 ⭐⭐⭐

| 项目 | 评估 |
|------|------|
| **阳光高考 gaokao.chsi.com.cn** | 院校库、专业库信息丰富，但无系统征集志愿数据库 |
| **EOL API (api.eol.cn)** | 有分数线数据，但加密且需token |
| **数据覆盖** | 主要提供正常批次投档线，征集志愿数据不系统 |

#### 已知限制

- 阳光高考平台无专门的征集志愿数据板块
- EOL API 数据加密（`isEncryption:true`），需登录token解密
- API有频率限制（约50-100次/分钟），超限返回 `{"code":"1069"}`

---

### 2.4 高考直通车 / 夸克高考 / 百度AI助考 ⭐⭐

| 平台 | 评估 |
|------|------|
| **高考直通车** | 手机APP为主，数据不开放采集 |
| **夸克高考** | 夸克浏览器内置，无公开API |
| **百度AI助考** | 百度搜索页面，数据分散难系统采集 |

这些平台数据仅供参考，不适合程序化批量采集。

## 4. 采集策略建议

### 4.1 分层采集方案

```
第一层（快速启动）：dxsbb.com HTML表格数据
  ├─ 优先采集 2023-2025 年数据（HTML格式，无需OCR）
  ├─ 通过分类列表页发现URL
  └─ 按省份分批采集

第二层（补充扩展）：dxsbb.com 图片数据 + 更多年份
  ├─ 通过sitemap.xml发现所有URL
  ├─ 遍历dxsbb新闻ID范围，标题筛选
  └─ 图片数据使用OCR（PaddleOCR/Tesseract）

第三层（数据校验）：各省考试院官网
  ├─ PDF解析 + HTML解析
  ├─ 用于交叉验证dxsbb数据的准确性
  └─ 补充dxsbb缺失的数据
```

### 4.2 推荐优先采集列表

基于已验证的URL模式和标题规律，以下数据类型建议优先采集：

**2023-2025年征集志愿数据（按省份）：**
- [ ] 山东：常规批投档位次（第1/2/3次）
- [ ] 海南：本科A批/本科批征集志愿
- [ ] 广东：本科/专科征集志愿投档线
- [ ] 湖南：本科批征集志愿
- [ ] 江苏：本科/专科征集志愿
- [ ] 浙江：二段投档分数线（对应征集）
- [ ] 其他省份：通过分类页探索

### 4.3 数据字段标准化

建议统一输出以下字段：

```python
{
    "province": "省份名",          # 如 "海南"
    "year": 2023,                  # 数据年份
    "category": "物理类/历史类/理工/文史/综合",  # 科类
    "school_name": "院校名称",     # 如 "中国民航大学"
    "school_code": "院校代码",     # 如 "0102"
    "batch": "本科批/专科批",      # 批次
    "round": "第一次征集/第二次征集", # 征集轮次
    "plan_count": 6,               # 计划数（缺额人数）
    "actual_count": 6,             # 投档数
    "min_score": 577,              # 投档最低分
    "source": "dxsbb/考试院",      # 数据来源
    "source_url": "https://..."    # 来源URL
}
```

### 4.4 采集注意事项

1. **反爬策略**：dxsbb.com 通过 IIS 托管，无验证码限制，但建议请求间隔 1-2 秒
2. **编码问题**：页面为 UTF-8 编码，直接 `requests.get().text` 即可
3. **ID范围**：已知 dxsbb 新闻ID范围广（从 50000 到 149000+），2023-2025年数据可能集中在 100000-150000 范围
4. **图片识别**：对于图片格式的数据，优先使用 PaddleOCR（国产，中文字体识别效果好）
5. **数据验证**：采集完成后应抽样与省考试院官网数据交叉验证
