### EOL API（掌上高考数据接口，可程序化调用）

| 接口 | URL | 说明 |
|------|-----|------|
| 院校列表 | `https://api.eol.cn/gkcx/api/?access_token=&signsafe=&province_id=44&uri=apidata/api/gk/school/lists` | 可按省份获取院校基本信息（省份ID：11北京/44广东/45广西等） |
| 分数线 | `https://api.eol.cn/gkcx/api/?uri=apidata/api/gk/score/province` | ⚠️ 数据加密（isEncryption:true），需登录token解密 |

> ⚠️ EOL API 有频率限制（约50-100次/分钟），超限返回 `{"code":"1069","message":"访问太过频繁，请稍后再试"}`。建议间隔1秒以上。

### 实战数据获取经验

| 问题 | 解决方案 |
|------|---------|
| Clash代理(127.0.0.1:7890)导致SSL错误 | Python脚本中 `proxies={'http': None, 'https': None}` 或设置 `NO_PROXY=*` |
| 省考试院网站编码为GBK | `response.encoding = 'gbk'` 后再解析 |
| gaokao.cn要求登录 | 用EOL API替代（无需登录但数据加密） |
| 搜索引擎返回无关结果 | 使用精确长尾词：`"2025年 广东 美术类 综合分 一分一段表"` |

## 数据获取优先级

```
1. 省考试院官网 → 一分一段表 + 投档线（最权威）
2. 目标院校招生网 → 分专业录取数据（最精确）
3. 阳光高考平台 → 院校/专业信息（最全面）
4. 第三方平台 → 辅助参考（最便捷但有误差）
```

## 一分一段表说明

一分一段表（分段人数统计表）是省考试院在高考成绩公布时发布的官方数据，包含：

| 字段 | 说明 |
|------|------|
| 分数 | 高考总分（含加分） |
| 人数 | 该分数的考生人数 |
| 累计人数 | 该分数及以上累计有多少人（即位次上限） |

**使用方法：** 找到自己的高考分数 → 对应累计人数即为位次范围 → 取保守值（累计人数上限）作为参考位次。

## 院校录取数据说明

| 字段 | 说明 |
|------|------|
| 最低录取分 | 该校/专业录取的最后一名考生分数 |
| 最低录取位次 | 该校/专业录取的最后一名考生位次（核心参考） |
| 平均录取分 | 录取考生的平均分 |
| 录取人数 | 该专业/院校在该省录取人数 |

> **最低录取位次** 是最核心的参考指标，比最低录取分更稳定可靠。
