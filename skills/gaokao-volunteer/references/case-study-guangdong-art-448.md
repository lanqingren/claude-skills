# 案例二：广东2026美术类综合分448/排位16750（艺术类边缘分数）

## 输入

> 用户提供了查分短信截图，Agent识别出两组分数

```
历史类总分425 / 排位137200
美术与设计类合成总分448 / 排位16750
```

Agent 识别：广东省 / 美术与设计类 / 综合分448 / 排位16750（本科中段偏下）。

反推术科成绩：448 = 425×0.4 + 术科×1.5 → 术科≈185分（刚踩本科线）。

## 技术亮点

- 综合分公式自动验算（广东：文化×0.4+术科×1.5），反推术科成绩
- 三条线检查（文化课线/术科线/综合分线）
- **省外院校扩展**：v1.0只推荐省内，考生实际被广西柳州工学院录取 → v1.1修正为必须包含省外
- 投档数据来源：大学生必备网(dxsbb.com)图片 + 视觉识别提取
- 2023-2024两年数据5:3加权平均，标注波动范围和大小年风险
- 民办/公办明确标注学费差异
