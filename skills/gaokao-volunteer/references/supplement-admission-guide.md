# 征集志愿（补录）参考指南

> 最后更新：2026-07-02 | 对应 Skill v5.0.0

## 什么是征集志愿（补录）

征集志愿，俗称**补录**，是指每批次录取结束后，省教育考试院将**未完成招生计划**的院校和专业缺额向社会公布，供**未被录取**且**达到相应批次线**的考生再次填报志愿。

### 产生原因

1. **生源不足**：院校在该省招生计划未录满
2. **退档缺额**：投档后考生因不服从调剂/单科成绩/体检等原因被退档，产生空额
3. **新增计划**：院校后期追加招生计划

### 征集志愿的关键特征

| 特征 | 说明 |
|------|------|
| **时间窗口极短** | 通常只有 12-24 小时填报时间 |
| **分数可能下降** | 征集志愿投档线通常低于正常批次投档线，但也可能出现"越征集越高"的情况 |
| **冷热不均** | 热门院校/专业征集志愿投档线可能反超正常批次 |
| **多轮征集** | 部分省份会有第二次甚至第三次征集（如本科批征集→降分征集） |
| **降分征集** | 部分省份允许低于批次线一定分数（如20分以内）的考生参加征集 |

## 各批次征集志愿的典型安排

### 本科提前批征集
- **时间**：7月上旬
- **特点**：军校/公安/公费师范生等特殊类型因体检政审严苛，缺额较多
- **降分**：通常不降分，要求过批次线

### 本科批征集
- **时间**：7月中下旬
- **特点**：缺额主要来自民办/独立学院/偏远地区公办
- **降分**：部分省份第二次征集可降 10-20 分

### 专科批征集
- **时间**：8月
- **特点**：缺额最大，多轮征集为主
- **降分**：通常降分幅度大（可达 30-50 分）

## 征集志愿的策略建议

### 谁适合关注征集志愿

1. **滑档考生**：正常批次因志愿填报过高未被录取
2. **退档考生**：被投档后因不符合条件被退档
3. **踩线考生**：分数刚过批次线，想通过征集冲公办
4. **愿意接受降档**：本科线上考生愿意读专科的好专业

### 填报建议

| 策略 | 说明 |
|------|------|
| **快速决策** | 征集志愿填报时间窗口短，提前做好院校调研 |
| **梯度填报** | 同样遵循冲稳保原则，不要全填热门 |
| **关注降分** | 部分省份第二次征集有降分，低于批次线也可尝试 |
| **优先公办** | 征集志愿中公办院校缺额较少但存在，优先选 |
| **核实费用** | 征集志愿中常有中外合作/民办，确认学费后再填 |
| **关注专业** | 不要仅盯院校，征集的专业往往较冷门 |

### 需要避免的坑

1. **"越征集越高"陷阱**：热门院校/专业在征集时竞争可能更激烈（因为全省滑档高分考生都在抢）
2. **调剂风险**：征集志愿通常不设专业调剂，录取即锁定该专业
3. **信息延迟**：考试院通知征集志愿的时间往往是下午到晚上，要随时关注
4. **降分有限**：不要误以为征集就一定降分，大部分公办院校征集不降分
