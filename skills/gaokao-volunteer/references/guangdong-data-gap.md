# 广东省数据缺口与处理方案

## ⚠️ 问题概述（2026-06-24修正）

广东省在 `province_classified.json` 中2024年历史类为0条，**但 multi_province/ 目录下有完整专业组级数据**：

- `multi_province/广东_2024_admission.json`：**571条历史类** + 1,248条物理类（2000条总数据）
- `multi_province/广东_2023_admission.json`：有历史类数据
- `province_classified.json` 中：2024历史类 0条，2023历史类仅6条专科，2024物理类91条

## 影响范围

当用户查询广东历史类志愿方案时，无法直接使用 `gaokao_tools.py recommend` 命令（会报"未找到广东省2024的院校录取数据"）。

## 可用数据源（更新排序）

| 数据源 | 路径 | 内容 | 优先级 |
|--------|------|------|--------|
| **multi_province 历史类** | `multi_province/广东_2024_admission.json` | **571条**历史类专业组投档数据（2024） | ⭐⭐⭐ 首选 |
| **multi_province 历史类** | `multi_province/广东_2023_admission.json` | 2023年历史类数据 | ⭐⭐⭐ |
| 2025历史类一分一段表 | `gd_extract_2025/1.广东省2025年高考普通类（历史）分数段统计表（含本、专科层次加分）.pdf` | 分数-位次映射 | ⭐⭐ |
| 2025物理类一分一段表 | `gd_extract_2025/2.广东省2025年高考普通类（物理）分数段统计表（含本、专科层次加分）.pdf` | 分数-位次映射 | ⭐ |
| 2024物理类院校数据 | `province_classified.json` → `|2024|物理类` | 91所院校 | ⭐ |
| 2024年PDF分数段表 | `gd_extract/`或`gd_2024_scores/` | 16个PDF | ⭐ |
| gd_admission zip | `gd_admission/gd_2024_admission.zip` | 待解压查看 | ❓ |

### JSON关键字段

```json
{
  "name": "院校名称",
  "local_type_name": "历史类/物理类/综合",
  "min": 512,          // 最低录取分
  "min_section": 31824, // 最低录取位次
  "city_name": "广州市",
  "nature_name": "公办/民办",
  "level_name": "本科",
  "local_batch_name": "本科批"
}
```

筛选方式：`d.get('local_type_name') == '历史类'`

## 处理策略

### 方案A：multi_province 历史类数据（推荐，已更正）

1. 解析2025年历史类PDF一分一段表，将用户分数/位次换算对应年份关系
2. 从 `multi_province/广东_2024_admission.json` 加载历史类数据：
   - `d.get('local_type_name') == '历史类'` 过滤
   - 解析 `min`（最低分）+ `min_section`（最低位次），注意同校有多个专业组
3. 也从 `广东_2023_admission.json` 加载做两年对比
4. 每个院校展示专业组位次范围（最低分专业组~最高分专业组）
5. 按位次分档：冲（20000~31000）/ 稳（31000~38000）/ 保（38000~50000）
6. 每档至少10所院校
7. 应用通胀校正：2024→2025广东历史类通胀约+25分

### 方案B（备用）：物理类数据作为层次参考

仅当 multi_province 数据不可用时使用：
1. 解析2025年历史类PDF一分一段表
2. 用2024年物理类院校数据作为院校层次参考
3. 应用通胀校正
4. **明确标注数据来源限制**
