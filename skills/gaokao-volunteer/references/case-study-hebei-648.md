# 案例一：河北2024物理类648分（高分段普通类）

## 输入

> 用户发送了一张高考成绩短信截图

```
【河北省教育考试院】同学，您的2024年高考成绩如下：
语文126，数学125，英语136，物理80，化学91，生物90，总分648。
```

Agent 自动识别：河北省 / 物理类 / 物化生组合 / 648分。

## 输出报告结构

### 1. 考生定位

| 项目 | 数据 |
|------|------|
| 省份/科类 | 河北省 / 物理类（物化生） |
| 总分 | 648分（超出特招线142分） |
| 估算排位 | 第1500-2200名 |
| 标定依据 | 掌上高考工具确认：528分=排位3754，推算648分排位 |

### 2. 科目优势分析

| 科目 | 分数 | 评价 | 适合方向 |
|------|------|------|----------|
| 英语 | 136 | 🟢 极强 | 国际化项目、出国深造 |
| 化学 | 91 | 🟢 优秀 | 化工、材料、药学、临床医学 |
| 生物 | 90 | 🟢 优秀 | 生物科学、医学、农学 |
| 物理 | 80 | 🔴 相对薄弱 | 避开纯物理/核工程 |

### 3. 冲稳保方案

| 档次 | 代表院校 | 数量 |
|------|---------|------|
| 🏃 冲刺(40-55%) | 北航、同济、哈工大(深圳)、北理、华东师大 | 5所 |
| ⚖️ 稳妥(65-85%) | 武大、华科、西交、中山、东南、天大、南开、厦大、电科、哈工大 | 10所 |
| 🛡️ 保底(90%+) | 北邮、华南理工、川大、西工大、湖大、大工、中南、重大 | 8所 |

### 4. 特色推荐

- **天津大学化工**（全国第一）← 化学91分高度契合
- **四川大学口腔医学**（全国第一）← 化生双优
- **中外合作办学项目** ← 英语136极具优势

### 5. 填报策略

河北采用"专业+院校"模式，本科批可填96个志愿，无调剂风险。建议排列：
- 第1-15志愿：冲刺档
- 第16-50志愿：稳妥档（主力）
- 第51-80志愿：保底档
- 第81-96志愿：兜底档

## 技术亮点

- 从短信截图自动识别省份、年份、各科成绩、选科组合
- 通过掌上高考(gaokao.cn)智能选大学工具获取标定点，推算排位
- 结合科目优势推荐匹配的专业方向（不只看分数匹配）
- 针对河北"专业+院校"模式给出96志愿排列策略
