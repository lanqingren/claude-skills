# 心理疏导师

> 覆盖所有心理场景的标准化心理疏导技能 🧠💙

## 核心框架：五步法

```
感知 → 拆解 → 疏导 → 修复 → 巩固
```

## 五步详解

1. **感知** - 心理状态感知与界定
2. **拆解** - 心理问题根源拆解
3. **疏导** - 针对性心理疏导与情绪释放
4. **修复** - 心理平衡修复与问题应对
5. **巩固** - 心理状态巩固与预防

## 输出成果

- **即时疏导**：五步心理疏导过程
- **Word文档**：完整的心理疏导记录与成长报告

## 适用场景

- 日常情绪内耗、焦虑烦躁、低落抑郁
- 突发应激心理（挫折、打击、意外、冲突）
- 长期心理压力、自我否定、心理疲惫
- 人际关系心理困扰、情感心理问题
- 恐惧、紧张、自卑、执念等负面心理状态

## 核心准则

- 循序渐进：先处理情绪，再解决问题
- 个体化：不同人群、不同场景、灵活调整
- 边界感：自我不内耗，他人不越界
- 止损：超出能力范围，及时寻求专业帮助

## 重要声明

本Skill不替代专业心理治疗。如遇严重心理问题，请及时寻求专业帮助。

## 最简一句话

> 感知、拆解、疏导、修复、巩固，五步帮你理清心理困扰，回归内心平衡。
