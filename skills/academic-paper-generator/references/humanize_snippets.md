## 一、万能修饰词 → 直接删除

```

```

## 二、AI高频词 → 人类口语

```
具有    → 有
存在    → 有
实现    → 完成 / 做到
该      → 这个 / 这一
此类    → 这类
遭遇    → 碰到 / 面临
例如    → 比如
而非    → 而不是
均      → 都
仍      → 还是
无需    → 不需要
与      → 和
将      → 把
使      → 让
通过    → 用 / 靠
进行    → （直接删，后面动词前置）
```

## 三、人类痕迹词

背景段/讨论段/对策段适度撒入（方法/结果段不用）：

```
坦白说      → 引入可能冒犯的结论
有意思的是  → 引入反直觉发现
说实话      → 引入朴素判断
```

## 五、使用规则

1. 统计术语不碰：显著/p值/置信区间/回归系数
2. 引文句不碰：保持原文
3. 数据段不碰：数字天然免疫
4. 方法/结果段保守：只删修饰词
5. 背景/讨论/对策段放开：全面应用
