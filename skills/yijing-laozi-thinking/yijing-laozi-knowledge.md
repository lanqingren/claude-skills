# 易经及老子思维模型 · 参考知识库

## 一、阴阳对耦分析详表

| 阴（隐性/柔弱/潜在） | 阳（显性/刚强/现实） | 互根关系 |
|---|---|---|
| 内在动机 | 外在行为 | 行为是动机的显现，动机是行为的根由 |
| 长期趋势 | 短期波动 | 短期波动受长期趋势制约，长期趋势由短期波动累积 |
| 潜在需求 | 已满足需求 | 满足需求后暴露新需求，新需求推动新供给 |
| 文化软力 | 制度硬力 | 制度保障文化传承，文化赋予制度合法性 |
| 沉默多数 | 意见领袖 | 领袖依靠沉默多数的力量，多数需要领袖来表达 |

**分析心法**：看到阳面时，追问「这里的阴是什么？」；看到阴面时，追问「它如何向阳转化？」

## 四、时位判断矩阵详解

### 4.1 四种时位状态及策略

```
                    当位（实力与位置匹配）
                         │
            ┌────────────┼────────────┐
            │            │            │
    顺时    │   乾健态势  │            │
   (时机    │   积极进取  │            │
    有利)   │   飞龙在天  │            │
            │            │            │
  ─────────┼────────────┼────────────┤
            │            │            │
    逆时    │   需待态势  │            │
   (时机    │   蓄势待发  │            │
    不利)   │   云上于天  │            │
            │            │            │
            └────────────┼────────────┘
                         │
                  不当位（实力与位置不匹配）

        顺时 + 不当位 → 谦退态势（以柔承刚，借力不逞强）
        逆时 + 不当位 → 潜藏态势（韬光养晦，厚积薄发）
```

### 4.2 时位判断的实操问题清单

**判断「时」—— 外部时机：**
- 行业/市场处于上升、平稳、下行还是转折期？
- 政策环境是否有利？
- 竞争格局是否有利于我方行动？
- 客户/受众需求是增长、平稳还是萎缩？

**判断「位」—— 自身位置：**
- 我的核心竞争力与当前要求是否匹配？
- 我在利益格局中处于核心还是边缘？
- 我的资源是否足够支撑当前目标？
- 我的话语权/影响力是否到位？

**组合策略：**
- 乾健（顺时+当位）：全力出击，但要防亢龙有悔
- 需待（逆时+当位）：等待时机，保持能力不衰退
- 谦退（顺时+不当位）：借势成长，不自量力硬上
- 潜藏（逆时+不当位）：沉潜蓄力，保全自身为先

## 五、以柔克刚策略详解

### 5.1 水之七善（基于老子第八章）

> 上善若水。水善利万物而不争，处众人之所恶，故几于道。

| 七善 | 原文 | 策略含义 | 商业应用 |
|------|------|---------|---------|
| 居善地 | 处众人之所恶 | 选择被忽视但有价值的领域 | 蓝海战略，避开红海 |
| 心善渊 | 心如深渊 | 深度思考，沉稳内敛 | 不急于表态，深入理解后再行动 |
| 与善仁 | 给予以仁 | 利他思维，创造共赢 | 为合作伙伴创造价值 |
| 言善信 | 说话守信 | 信用是最硬的通货 | 言出必行，建立品牌信任 |
| 正善治 | 治理有方 | 制度化、规范化 | 建立可持续的运营体系 |
| 事善能 | 做事有能力 | 能力是根本 | 持续提升核心能力 |
| 动善时 | 行动合时 | 时机是关键 | 不早不晚，恰到好处 |

### 5.2 柔刚策略选择决策树

```
面对的问题
    │
    ├─ 对手是否刚强？
    │   ├─ 是 → 能否避其锋芒？
    │   │   ├─ 能 → 以退为进，迂回突破
    │   │   └─ 不能 → 借力打力，化刚为柔
    │   └─ 否 → 保持柔势，防止自身刚化
    │
    ├─ 时间是否在我方？
    │   ├─ 是 → 持久战，耗对手锐气
    │   └─ 否 → 寻找对方弱点，精准一击
    │
    └─ 是否可以改变规则？
        ├─ 能 → 重新定义战场（如水改道）
        └─ 不能 → 在现有规则中找柔性的缝隙
```
