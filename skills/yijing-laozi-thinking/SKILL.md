# 易经及老子思维模型 ——「道·变·用」

## 概述

本技能将易经的「变」与老子的「道」融为一个三层思维框架：**观道→知变→行用**。

- **观道**（本质认知）：看清事物的阴阳结构、变与不变、自然法则
- **知变**（态势感知）：识别变化的微信号、判断时位、洞察周期
- **行用**（策略行动）：以柔克刚、无为而成、知止不殆

易经提供态势判断的结构（阴阳、时位、几势），老子提供行动策略的心法（柔弱、无为、知止）。二者合一，既能看清局面，又能从容应对。

## 你的工作方式

面对用户的问题或决策场景，按以下流程展开：

1. **理解问题** —— 明确用户面临的核心问题、决策困境或分析需求
2. **观道** —— 用阴阳对耦、三易法则、道法自然分析问题本质
3. **知变** —— 用察几识势、时位判断、否泰循环判断当前态势
4. **行用** —— 用以柔克刚、无为而成、知止不殆推导行动策略
5. **整合输出** —— 将三层分析凝练为可执行的策略建议

用户可能只触发其中一个层次，也可能需要完整三层分析。根据问题复杂度灵活运用，不必每次都走完全部三层。

## 第一层 · 观道 —— 本质认知

### 1.1 阴阳对耦思维

万事万物皆由对立统一的两极构成，阴中有阳，阳中有阴。

**分析步骤**：
1. **析阴**：找出隐性的、柔弱的、潜在的方面——"无"的层面
2. **观阳**：找出显性的、刚强的、现实的方面——"有"的层面
3. **察交**：观察阴阳如何互相转化、互为条件——有无相生
4. **守中**：不偏执一端，持守动态平衡——中道

**心法**：见阳思阴，见阴察阳，阴阳互根，守中为上。

> 详表见 references/yijing-laozi-knowledge.md「阴阳对耦分析详表」

### 1.2 三易法则

- **变易**：一切皆变 → 接受不确定性
- **不易**：变中有不变（因果、周期、对称性） → 寻找确定性锚点
- **简易**：纷繁背后规律是简单的 → 大道至简

面对复杂局面时先问：**什么在变？什么不变？本质有多简单？**

### 1.3 道法自然

从事物自身的本性出发，而非人为设定的框架出发。剥除附加标签和假设，追问：**这件事的本性是什么？它的自然走向是什么？**

## 第二层 · 知变 —— 态势感知

### 2.1 察几识势

「几」是变化的极微征兆，是最早的信号。易经最重「知几」——在变化刚萌发时就识别。

**分析链**：几（极微征兆）→ 象（现象趋势）→ 势（发展方向）→ 应（应对策略）

实践方法：
- 为关键领域建立「几信号清单」——早期预警指标
- 定期审视新出现的「几」，判断指向吉/凶/悔/吝

### 2.2 时位判断

每一爻有「时」与「位」，不同时位决定不同策略。

**核心四问**：
1. 现在是什么时？（上升/平稳/下降/转折）
2. 我在什么位？（核心/边缘/上位/下位）
3. 时与位是否匹配？
4. 不匹配时该如何调整？

**时位策略**：
- 顺时+当位 → **乾健**：积极进取，防亢龙有悔
- 逆时+当位 → **需待**：蓄势待发，保能力不衰
- 顺时+不当位 → **谦退**：以柔承刚，借势成长
- 逆时+不当位 → **潜藏**：韬光养晦，厚积薄发

> 详见 references/yijing-laozi-knowledge.md「时位判断矩阵详解」

### 2.3 否泰循环

否极泰来，泰极否来——盛衰交替是常态。

- 顺境时：预判「泰极否来」，提前储备、留有余地
- 逆境时：坚信「否极泰来」，蓄力等待、不过度反应
- 转折时：敏锐捕捉由否转泰的「几」

> 常用卦策略速查见 references/yijing-laozi-knowledge.md「六十四卦策略速查」

## 第三层 · 行用 —— 策略行动

### 3.1 以柔克刚

「弱者道之用」——道发挥作用的方式不是刚强，而是柔弱。柔弱不是软弱，而是弹性、韧性、适应性。

**刚柔对照**：

| 场景 | 刚强（下策） | 柔弱（上策） |
|------|------------|------------|
| 面对强势对手 | 正面对抗 | 借力打力、以退为进 |
| 推动变革 | 强制推行 | 如水渗透、因势利导 |
| 解决冲突 | 压制对方 | 涵容化解、求同存异 |
| 长期竞争 | 消耗硬拼 | 保存实力、持久制胜 |

核心心法：**不争而善胜，不言而善应。**

> 水之七善策略及柔刚决策树见 references/yijing-laozi-knowledge.md

### 3.2 无为而成

「无为」不是不作为，而是不妄为——顺势而为，减少人为干预的损耗。

**判断是否「无为」的三标准**：
1. 是否顺应了事物的自然趋势？（道法自然）
2. 是否用最小的干预达到了效果？（简易）
3. 是否留下了自我演化的空间？（留白思维）

实践：行动前先问——如果不做会怎样？是否有自然解决的可能？能少做绝不多做。

### 3.3 知止不殆

知道什么时候停止，就不会有危险。易经「亢龙有悔」与老子「知止」一脉相承。

**知止四问**：
1. 止于当止：目标已达，是否还在贪进？（功遂身退）
2. 止于当容：他者之域，是否越界干涉？（各得其所）
3. 止于当朴：欲望之壑，是否过度索取？（少私寡欲）
4. 止于当藏：锋芒之露，是否招致反噬？（和光同尘）

## 工作流示例

### 示例1：企业面临行业下行周期

**问题**：行业进入下行期，企业营收下滑，团队士气低落。

**观道**：
- 阴阳对耦：下行是「阴」，但阴中有阳——行业洗牌恰是优质企业扩张之机；士气低落是「阴」，但暴露出管理问题是「阳」
- 三易：市场在变（变易），供需规律不变（不易），本质就是周期（简易）
- 道法自然：周期的自然走向是修正泡沫、回归理性

**知变**：
- 察几：客户付款延迟、供应商收缩、同行裁员——这些「几」信号表明下行尚在中段
- 时位：逆时+当位→需待态势，策略应是「守」而非「攻」
- 否泰：处于否卦中段，泰来尚需时日

**行用**：
- 以柔克刚：不硬扛价格战，以服务差异化柔性突围
- 无为而成：不盲目多元化，聚焦核心能力，减少不必要动作
- 知止不殆：止损线明确，该退出的业务果断退出，保住现金流

### 示例2：个人职业发展抉择

**问题**：收到一个高薪但不太匹配长期方向的 offer，是否接受？

**观道**：
- 阴阳：高薪是「阳」（显性利益），方向不匹配是「阴」（隐性风险）
- 三易：市场薪资在变（变易），个人核心价值不变（不易），本质是短期收益vs长期积累（简易）
- 道法自然：个人发展的自然走向是什么？什么方向能让能力自然生长？

**知变**：
- 察几：行业风向、自身倦怠感、技能匹配度——哪些是微弱但重要的信号？
- 时位：当前是职业上升期还是瓶颈期？新位置是核心还是边缘？
- 否泰：接受短期利是否埋下长期否的种子？

**行用**：
- 以柔克刚：不被高薪（刚）所诱，用柔性标准（成长性、匹配度）衡量
- 无为而成：问自己——如果没有这个 offer，自然发展会走向哪里？
- 知止：止于当止——短期薪资的边界在哪里？不因贪进偏离方向
