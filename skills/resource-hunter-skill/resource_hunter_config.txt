资源猎手 V1.0.1 配置说明
=============================
一、基础信息
技能名称：资源猎手·谜语破译版
技能版本：1.0.1
适配QClaw版本：≥2.0
功能概述：自动搜索UP主评论区藏链，破译多种谜语，筛选免费、可靠资源，支持小说、动漫、漫画、电影、剧集、电子书、有声书、软件、素材、游戏、纪录片、公开课等多种资源类型，具备去重、防炸链、存活检测功能，支持磁力/网盘解析；新增模糊查询功能，支持用户无具体名称、仅提供剧情描述或功能要素时，自动识别作品/软件并推荐，要素库无匹配时可自动扩展获取相关作品，提升查询成功率。

二、核心配置参数（可修改，位于.py文件CONFIG字典中）
1. timeout_check: 5  # 存活检测超时时间（秒），建议5-10秒
2. min_score: 65     # 最低可靠分，低于该分数的资源将被过滤
3. banned_domains:  # 炸链域名黑名单，新增炸链域名可直接添加
4. dead_patterns:   # 无效链接特征，新增无效关键词可添加正则表达式
5. magnet_resolvers: # 磁力解析接口，可替换为真实可用接口（当前接口报错，需替换）
6. pan_resolvers:    # 网盘解析接口，支持百度/阿里云/蓝奏云，可替换为真实接口（当前接口报错，需替换）
7. split_chars:      # 藏链分隔符，可添加UP主常用分隔符
8. element_match:    # 要素-作品匹配库，可新增/修改要素与对应作品，适配模糊查询
9. plot_match:       # 剧情关键词匹配库，可新增/修改剧情关键词与对应作品，提升模糊识别准确率
10. element_extend_map: # 要素扩展映射表（新增），用于要素库无匹配时自动扩展相似要素，可根据需求新增/修改相似要素映射

三、依赖环境（无需额外安装，QClaw自带）
- qclaw（核心依赖）
- asyncio（异步处理）
- re（正则匹配）
- base64（Base64破译）
- urllib（URL解析）

四、修改说明
1. 解析接口修改：替换CONFIG中的magnet_resolvers和pan_resolvers为真实接口，当前接口报错（link fetch error、link dead），需优先替换，否则无法正常解析磁力/网盘链接。
2. 黑名单修改：在banned_domains中添加新的炸链域名，用引号包裹，逗号分隔
3. 分隔符修改：在split_chars中添加UP主常用的分隔符，如“，”“。”等
4. 可靠分修改：根据需求调整min_score，数值越高，筛选越严格
5. 资源类型扩展：若需新增更多资源类型，可修改.py文件中_guess_type方法和_riddle_templates字典
6. 模糊查询配置：
   - 要素匹配修改：在element_match中新增资源类型的要素与对应作品，格式参考现有配置
   - 剧情匹配修改：在plot_match中新增资源类型的剧情关键词、作品名称和置信度，提升模糊识别准确率
   - 要素扩展修改（新增）：在element_extend_map中新增/修改各资源类型的要素相似映射，格式参考现有配置，可根据用户需求扩展相似要素，提升要素无匹配时的扩展成功率

五、注意事项
1. 本技能仅用于搜索公开免费资源，不涉及盗版侵权
2. 解析接口需替换为合规接口，当前内置接口报错，避免因接口无效导致审核失败或功能异常
3. 定期更新banned_domains和dead_patterns，提升防炸链效果
4. 新增资源类型后，建议同步更新SKILL.md中的功能介绍和使用方法，确保上架审核通过
5. 可根据用户需求，扩展element_match、plot_match中的匹配规则，以及element_extend_map中的要素扩展映射，提升模糊查询和要素扩展的准确率
6. 要素扩展映射表（element_extend_map）需与element_match中的要素对应，避免扩展后仍无匹配的情况，建议定期维护更新
