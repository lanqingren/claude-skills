# 资源猎手·谜语破译版（V1.0.1）
## 技能介绍
资源猎手 V1.0.1，专注于免费资源搜索与UP主藏链破译，支持小说、动漫、漫画、电影、剧集、电子书（PDF/EPUB/MOBI）、有声书、软件（APP）、设计素材（PSD/PPT/模板）、游戏、纪录片、公开课等多种资源类型，自动扫描UP主评论区、简介中的藏链，破译多种常见谜语/暗号，筛选可靠、免费、可访问的资源路径，同时具备去重、防炸链、存活检测功能，支持磁力链、网盘解析，无需手动操作，轻松获取各类资源。

新增核心功能：模糊查询与要素/剧情匹配，支持用户无具体作品名称、仅提供剧情描述（如“找一个女孩当魔女去旅行的动漫”）或功能要素（如“找能编辑视频的软件”）时，自动识别匹配相关作品/软件；**要素库无匹配时，将自动扩展相似要素，获取相关作品**，大幅提升模糊查询成功率，解决用户描述模糊、要素匹配不到的痛点。

## 核心功能亮点
1.  资源种类全面：覆盖12种高频资源类型，从影视娱乐（小说、动漫、电影）到学习办公（电子书、公开课、素材），再到工具娱乐（软件、游戏），一站式满足所有免费资源搜索需求。
2.  真人级谜语破译：支持Base64、倒序、文字符号替换、分隔符隐藏等多种UP主常用藏链方式，自动破译，无需手动计算。
3.  三重安全筛选：去重（避免重复链接）、防炸链（过滤诈骗/付费/失效链接）、存活检测（确保链接可访问），提升使用体验。
4.  双模式获取：支持用户手动选择资源路径，或默认按靠谱度自动尝试，直到获取成功。
5.  磁力/网盘解析：内置解析接口，可将磁力链、网盘链接解析为可直接访问/下载的地址，无需额外工具（注：当前内置接口报错，需替换为真实合规接口）。
6.  适配多平台：支持B站等平台UP主藏链搜索，贴合用户真实找链场景，不同资源类型对应专属藏链模板，破译准确率更高。
7.  模糊查询适配：支持剧情描述、功能要素模糊搜索，要素库无匹配时自动扩展相似要素，获取相关作品，解决用户记不清具体作品名称、仅知道大致内容且要素匹配不到的痛点，交互更智能。

## 使用方法
### 一、常规搜索（已知具体作品/软件名称）
1.  触发方式：输入包含“找”+资源类型+资源名称的指令，例如：
    - 找小说 诡秘之主
    - 找动漫 间谍过家家 评论区资源
    - 找电影 沙丘2
    - 找电子书 三体 PDF
    - 找软件 PS 破解版
    - 找素材 海报模板
    - 找公开课 大学计算机基础
2.  技能执行：输入指令后，技能自动识别资源类型，搜索资源、扫描藏链、破译谜语、筛选链接。
3.  资源选择：技能展示筛选后的可用路径，标注资源类型，输入序号选择，或回复“默认”，技能自动按靠谱度尝试获取。
4.  结果查看：获取成功后，技能返回可直接使用的资源地址（在线观看/磁力/网盘解析地址），标注对应资源类型。

### 二、模糊搜索（未知具体名称，仅知道剧情/功能要素）
1.  触发方式：输入包含“找”+资源类型+剧情/功能描述的指令，例如：
    - 找动漫 一个女孩当魔女，到处旅行
    - 找软件 能编辑视频，拼接片段、加特效
    - 找小说 穿越到异世界，能死而复生
    - 找素材 简约风格的海报模板
    - 找电影 关于魔女，治愈系的
2.  技能执行：输入指令后，技能自动识别资源类型，根据剧情/功能要素匹配相关作品/软件；若要素库无直接匹配，将自动扩展相似要素（如“魔女”扩展为“魔法少女、女巫”），匹配相关作品/软件，展示匹配结果（带匹配度）。
3.  确认选择：输入序号选择你要找的内容，或回复“新增描述”补充更多细节，回复“其他”重新搜索。
4.  资源获取：确认作品/软件后，技能自动搜索该内容的藏链、破译谜语、筛选链接，后续操作与常规搜索一致。
