# JD匹配评分规则

## 评分维度

### 1. 技能匹配度（权重40%）

计算方式：
```
技能匹配分 = (命中的必备技能数 / JD必备技能总数) × 60 
           + (命中的加分技能数 / JD加分技能总数) × 40
```

示例：
- JD要求：Java(必备)、Spring(必备)、MySQL(必备)、Redis(加分)、分布式(加分)
- 简历有：Java、Spring、Redis、高并发
- 计算：(2/3)×60 + (1/2)×40 = 40 + 20 = 60分

### 2. 经历相关性（权重30%）

根据经历与JD职责的匹配程度评分：
- 高度相关（职责完全匹配）：90-100分
- 中度相关（职责大部分匹配）：60-89分
- 低度相关（职责部分匹配）：30-59分
- 不相关：0-29分

### 3. 亮点命中（权重20%）

简历中的亮点标签与JD加分项的匹配：
- 命中高价值亮点（如：大厂经验、高并发、团队管理）：每个+15分
- 命中普通亮点：每个+10分
- 最高100分

### 4. 年限匹配（权重10%）

| 情况 | 得分 |
|------|------|
| 完全符合 | 100分 |
| 超出要求 | 90分 |
| 略低于要求（1年内） | 70分 |
| 低于要求较多 | 40分 |

## 总分计算

```
总分 = 技能匹配分×0.4 + 经历相关性×0.3 + 亮点命中×0.2 + 年限匹配×0.1
```

## 匹配度等级

| 总分 | 等级 | 建议 |
|------|------|------|
| 85-100 | 高度匹配 | 强烈建议投递 |
| 70-84 | 良好匹配 | 建议投递 |
| 55-69 | 基本匹配 | 可以投递，补充材料 |
| 40-54 | 匹配较低 | 慎重考虑 |
| <40 | 不匹配 | 不建议投递 |

## 缺失项提示

当某项JD要求未在知识库找到匹配时，明确标注：
- ❌ **缺失**：知识库完全没有相关素材
- ⚠️ **弱匹配**：有相关但不够强
- ✅ **匹配**：有较好的相关素材

## 示例

### JD
```
职位：高级Java开发工程师
要求：
- 3-5年Java开发经验（必备）
- 熟悉Spring全家桶（必备）
- 熟悉MySQL、Redis（必备）
- 有分布式系统经验（加分）
- 有高并发经验（加分）
- 有金融行业背景（加分）
```

### 匹配结果
```
技能匹配：70分
- Java ✅
- Spring ✅
- MySQL ✅
- Redis ✅
- 分布式 ⚠️（有了解但项目不多）
- 高并发 ❌（缺失）
- 金融 ❌（缺失，但有电商经验）

经历相关性：85分
- 有服务端开发经验，职责匹配度高

亮点命中：60分
- 大厂经验 ✅
- 团队管理 ✅

年限匹配：100分
- 4年经验，符合要求

总分 = 70×0.4 + 85×0.3 + 60×0.2 + 100×0.1 = 75.5分
等级：良好匹配
```
