# job-hunting-hub 🔍💼

求职全流程管理技能 - 让AI帮你搞定找工作这件事

## 功能模块

### 1. 简历知识库 📚
- 模块化存储工作经历、项目经历、技能标签
- 自动标签体系（技术栈、行业、软技能、语言能力）
- 支持Markdown/Word双格式导出

### 2. JD智能匹配 🎯
- 粘贴JD自动匹配简历内容
- 四级匹配度评分（≥85%高匹配 / 70-84%良好 / 55-69%基本 / <55%低匹配）
- 自动生成针对性简历

### 3. 公司信息查询 🏢
- 集成天眼查/企查查查询能力
- 自动录入：成立时间、注册资金、规模、融资状态、核心业务、技术优势
- 一键生成公司分析报告

### 4. 投递进度管理 📊
- Excel表格自动维护投递记录
- 跟踪投递状态、回复情况、面试进度
- 支持每日/每周统计分析

### 5. 记忆持久化 💾
- 所有信息同步存入记忆系统
- 跨会话可用，不会"失忆"

### 6. AI简历优化 🤖
- 针对ATS（简历筛选系统）优化建议
- 关键词密度分析
- 格式规范检查

## 依赖技能

```yaml
dependencies:
  required:
    - docx          # 简历Word版生成
    - excel_master  # 投递记录表维护
  recommended:
    - tianyancha-cn # 企业信息查询
    - pdf           # 简历PDF版生成
    - topic_tracking # 公司动态追踪
```

## 使用方法

### 安装方式

1. **Coze商店安装**：搜索 `job-hunting-hub`
2. **手动安装**：下载本项目，上传到你的Coze工作空间
3. **ClawHub安装**：`https://clawhub.ai/your-name/job-hunting-hub`

### 快速开始

```
# 录入简历信息
"帮我记录一下我的工作经历：xxx"

# JD匹配
"这是JD：xxx，帮我匹配一下简历"

# 查询公司
"帮我查一下XX公司的信息"

# 更新投递进度
"XX公司回复我了，约了下周面试"
```
