## 概览
本文档收录公文写作中的高频易错点，通过案例分析和规范说明，帮助避免常见错误。

## 核心内容

### 1. 标题常见错误

#### 错误1: 标题结构不完整
**错误示例**:
- 关于申请增加编制的请示（缺少发文机关）
- XX局关于加强管理的通知（事由不明确）
- 工作报告（缺少发文机关和事由）

**正确示例**:
- XX市机构编制委员会关于申请增加编制的请示
- XX局关于加强安全生产管理的通知
- XX局2025年度工作情况报告

**规范说明**:
标题必须包含"发文机关+关于+事由+文种"四要素，结构完整，事由明确。

#### 错误2: 标题中"关于"与"申请"、"请求"重复
**错误示例**:
- XX局关于申请追加经费的请示
- XX局关于请求批准立项的报告

**正确示例**:
- XX局关于追加经费的请示
- XX局关于立项的请示

**规范说明**:
"关于"与"申请"、"请求"语义重复，不能同时使用。

#### 错误3: 事由冗长
**错误示例**:
- XX局关于贯彻落实市委市政府关于加强环境保护工作若干意见的实施方案的通知（事由过长，超过50字）

**正确示例**:
- XX局关于加强环境保护工作的实施方案的通知
- 或: XX局关于《XX市关于加强环境保护工作的若干意见》的实施方案

**规范说明**:
事由应简洁明了，一般不超过30字，特殊情况不超过50字。

#### 错误4: 文种误用
**错误示例**:
- XX局关于开展检查工作的报告（应为"通知"）
- XX局关于批准XX事项的通知（应为"批复"）

**正确示例**:
- XX局关于开展检查工作的通知
- XX局关于批准XX事项的批复

**规范说明**:
根据行文目的和行文关系正确选择文种，不要混用。

### 2. 主送机关常见错误

#### 错误1: 请示有多个主送机关
**错误示例**:
```
主送：市政府，省财政厅：
```

**正确示例**:
```
主送：市政府：
```

**规范说明**:
请示只能写一个主送机关，如有需要，可抄送其他机关。

#### 错误2: 主送机关格式不规范
**错误示例**:
```
主送：各县（区）人民政府，市政府各部门、各直属机构
```
（缺少冒号）

**正确示例**:
```
主送：各县（区）人民政府，市政府各部门、各直属机构：
```

**规范说明**:
主送机关名称后必须加冒号。

#### 错误3: 主送机关未顶格
**错误示例**:
```
标题

  主送：市政府：
```

**正确示例**:
```
标题

主送：市政府：
```

**规范说明**:
主送机关必须顶格编排。

#### 错误4: 主送机关名称不规范
**错误示例**:
```
主送：市府、教育局：
```

**正确示例**:
```
主送：市人民政府，市教育局：
```

**规范说明**:
主送机关应使用全称或规范化简称，不能随意简化。

### 3. 正文常见错误

#### 错误1: 请示夹带报告事项
**错误示例**:
```
关于追加经费的请示

市政府：
根据工作需要，我局拟追加经费XX万元。同时，汇报我局近期工作情况如下：一、……二、……
以上请示，妥否，请批示。
```

**正确示例**:
```
关于追加经费的请示

市政府：
根据工作需要，我局拟追加经费XX万元，用于……具体如下：一、……二、……
以上请示，妥否，请批示。

关于近期工作情况的报告

市政府：
近期我局……（具体工作情况）
特此报告。
```

**规范说明**:
请示必须一文一事，不能夹带报告事项。如需汇报工作，应另写报告。

#### 错误2: 报告夹带请示事项
**错误示例**:
```
关于工作情况的报告

市政府：
……（汇报工作情况）
另外，因工作需要，特申请追加经费XX万元，请予批准。
以上报告，请审阅。
```

**正确示例**:
```
关于工作情况的报告

市政府：
……（汇报工作情况，不夹带请示）
特此报告。
```

**规范说明**:
报告不能夹带请示事项，如需请示，应另写请示。

#### 错误3: 逻辑层次混乱
**错误示例**:
```
……
一是加强组织领导，成立专项工作领导小组。二是加大资金投入，确保项目顺利实施。加强督导检查，定期通报进展情况。三是强化宣传引导，营造良好氛围。
```

**正确示例**:
```
……
一是加强组织领导，成立专项工作领导小组。二是加大资金投入，确保项目顺利实施。三是加强督导检查，定期通报进展情况。四是强化宣传引导，营造良好氛围。
```

**规范说明**:
正文应层次清晰，逻辑连贯，避免内容交叉或遗漏。

#### 错误4: 内容空洞，无实质内容
**错误示例**:
```
……
要加强领导，明确责任。要完善机制，强化措施。要加大投入，保障落实。要注重实效，确保质量。
```

**正确示例**:
```
……
一是加强组织领导。成立由XX任组长的专项工作领导小组，下设办公室，负责统筹协调。二是完善工作机制。建立月调度、季通报制度，定期召开推进会。三是加大资金投入。安排专项资金XX万元，用于……四是强化督导考核。将此项工作纳入年度考核，实行定期通报。
```

**规范说明**:
正文内容要具体明确，有实质性措施和要求，避免空泛表述。

### 4. 语言风格常见错误

#### 错误1: 口语化表达
**错误示例**:
- 咱们要好好干
- 大家都要努力
- 搞快点
- 事儿挺多的

**正确示例**:
- 要扎实工作
- 全体人员要履职尽责
- 加快推进
- 工作任务繁重

**规范说明**:
公文语言应准确、简洁、庄重、规范，避免口语化表达。

#### 错误2: 网络用语
**错误示例**:
- 点赞
- 打call
- 冲鸭
- 安排

**正确示例**:
- 给予肯定和支持
- 积极响应
- 加油鼓劲
- 部署落实

**规范说明**:
公文不得使用网络用语，保持严肃性。

#### 错误3: 生僻词和专业术语过多
**错误示例**:
```
……本方案基于XX理论，采用XX算法，通过XX建模，实现XX优化……
```

**正确示例**:
```
……本方案运用科学方法，优化工作流程，提升工作效率……
```

**规范说明**:
公文应通俗易懂，避免过多使用生僻词和专业术语。

#### 错误4: 夸张和不实表述
**错误示例**:
- 取得了举世瞩目的成就
- 实现了历史性跨越
- 创造了前所未有的奇迹

**正确示例**:
- 取得了显著成效
- 实现了较大提升
- 取得了良好效果

**规范说明**:
公文表述应实事求是，不夸大不缩小。

### 5. 格式常见错误

#### 错误1: 发文字号格式错误
**错误示例**:
- 国办发[2026]12号（括号错误）
- 国办发（2026）012号（编虚位）
- 国办发2026年第12号（格式不规范）

**正确示例**:
- 国办发〔2026〕12号

**规范说明**:
发文字号格式为"代字+〔年份〕+顺序号"，年份用六角括号，顺序号不编虚位。

#### 错误2: 成文日期格式错误
**错误示例**:
- 2026年04月03日（月份编虚位）
- 二〇二六年四月三日（使用汉字）
- 2026.04.03（格式不规范）

**正确示例**:
- 2026年4月3日

**规范说明**:
成文日期使用阿拉伯数字，年月日齐全，月份不编虚位。

#### 错误3: 标点符号使用错误
**错误示例**:
```
一、加强领导，
```
（层次序数后加标点）

**正确示例**:
```
一、加强领导
```

**规范说明**:
层次序数后不加标点符号，空一格直接写内容。

#### 错误4: 附件说明格式错误
**错误示例**:
```
附件：1. XX方案；2. XX通知。
```
（附件名称后加分号和句号）

**正确示例**:
```
附件：1. XX方案
      2. XX通知
```

**规范说明**:
附件名称后不加标点符号，多个附件使用阿拉伯数字标注顺序号。

### 6. 文种混用常见错误

#### 错误1: 请示与报告混用
**错误示例**:
```
关于XX工作情况的请示
```

**正确示例**:
```
关于XX工作情况的报告
或
关于XX事项的请示
```

**规范说明**:
请示用于请求指示、批准，报告用于汇报工作、反映情况，不能混用。

#### 错误2: 通知与通报混用
**错误示例**:
```
关于表彰XX同志的通报（用于部署工作）
```

**正确示例**:
```
关于表彰XX同志的决定（用于部署工作）
或
关于表彰XX同志的通报（仅用于宣传典型）
```

**规范说明**:
通知侧重部署工作、告知事项，通报侧重表彰先进、批评错误、传达精神。

#### 错误3: 函与请示混用
**错误示例**:
```
XX局关于XX事项的函（主送机关为上级机关）
```

**正确示例**:
```
XX局关于XX事项的请示
```

**规范说明**:
函用于不相隶属机关之间，向直属上级机关行文应使用请示或报告。

## 检查清单

公文写作完成后，请检查以下内容：

**标题检查**:
- [ ] 标题是否包含"发文机关+关于+事由+文种"四要素
- [ ] 事由是否明确简洁（一般不超过30字）
- [ ] 是否存在"关于"与"申请"、"请求"重复使用
- [ ] 文种是否正确

**主送机关检查**:
- [ ] 请示是否只有一个主送机关
- [ ] 主送机关是否顶格编排
- [ ] 主送机关名称后是否加冒号
- [ ] 主送机关名称是否规范（全称或规范化简称）

**正文检查**:
- [ ] 请示是否一文一事，未夹带报告事项
- [ ] 报告是否未夹带请示事项
- [ ] 逻辑层次是否清晰
- [ ] 内容是否具体明确，有实质性措施

**语言风格检查**:
- [ ] 是否存在口语化表达
- [ ] 是否存在网络用语
- [ ] 生僻词和专业术语是否过多
- [ ] 表述是否实事求是，不夸大不缩小

**格式检查**:
- [ ] 发文字号格式是否正确（代字+〔年份〕+顺序号）
- [ ] 成文日期格式是否正确（阿拉伯数字，不编虚位）
- [ ] 标点符号使用是否正确
- [ ] 附件说明格式是否正确

**文种检查**:
- [ ] 文种选择是否正确
- [ ] 是否存在文种混用
- [ ] 结尾用语是否与文种匹配

### 7. 特殊场景处理规范

#### 7.1 涉密公文处理规范

**密级分类**:
- 绝密: 最重要的国家秘密，泄露会使国家安全和利益遭受特别严重的损害
- 机密: 重要的国家秘密，泄露会使国家安全和利益遭受严重的损害
- 秘密: 一般的国家秘密，泄露会使国家安全和利益遭受损害

**保密期限**:
- 绝密: 不超过30年
- 机密: 不超过20年
- 秘密: 不超过10年

**标注要求**:
- 位置: 公文首页左上角
- 格式: 密级 + ★ + 保密期限
- 示例: 绝密★30年、机密★20年、秘密★10年

**传递要求**:
- 必须通过机要传递，不得使用普通邮政
- 严格控制知悉范围
- 建立登记制度，记录收发文情况
- 不得使用非涉密计算机处理涉密公文

#### 7.2 紧急公文处理规范

**紧急程度分类**:
- 特急: 需要立即办理，不得延误
- 加急: 需要尽快办理，有明确时限要求

**标注要求**:
- 位置: 公文首页左上角（如同时标注密级，密级在第一行，紧急程度在第二行）
- 格式: 使用三号黑体，单独一行
- 示例: 特急、加急

**适用场景**:
- 特急: 重大突发事件、紧急决策部署等
- 加急: 有明确办理时限的重要事项

**处理要求**:
- 收文后立即办理，不得拖延
- 建立督办机制，跟踪办理进度
- 办理结果要及时反馈

#### 7.3 涉外公文注意事项

**格式要求**:
- 使用国家标准公文格式
- 中文为主，必要时附外文翻译件
- 机关名称使用全称或规范化简称

**内容要求**:
- 准确表达我方立场和观点
- 语言准确、得体，避免歧义
- 涉及国际法、条约的内容要准确无误

**行文规则**:
- 涉外公文一般使用"函"或"通知"
- 注意国际惯例和外交礼仪
- 涉及敏感问题要严格把关

#### 7.4 电子化公文特殊要求

**电子签章**:
- 使用经认证的电子签章
- 电子签章与实物印章具有同等法律效力
- 建立电子签章使用管理制度

**PDF格式要求**:
- 使用符合国家标准的PDF格式
- 保证格式、字体、版式与纸质公文一致
- 文件大小适中，便于传输

**传输安全**:
- 使用加密传输通道
- 建立电子公文归档制度
- 确保电子公文的完整性和不可篡改性

**归档要求**:
- 电子公文与纸质公文同步归档
- 建立电子公文备份机制
- 保证电子公文的长期可读性

#### 7.5 公文发布渠道规范

**公开发布渠道**:
- 政府官网
- 政务新媒体（微信公众号、微博等）
- 新闻发布会
- 政府公报

**发布原则**:
- 凡是涉及公共利益、公众权益的公文，原则上应主动公开
- 涉密公文不得公开
- 公开发布前要严格审核

**发布时机**:
- 重要政策文件要配合政策解读同时发布
- 紧急事项要第一时间发布
- 一般公文应在发文后及时发布

### 8. 公文版本管理建议

#### 8.1 草稿管理

**版本编号**:
- 使用统一的版本编号规则: v1.0, v1.1, v2.0 等
- 小版本号修订（如 v1.1）表示小幅修改
- 大版本号修订（如 v2.0）表示重大调整

**版本记录**:
- 记录每个版本的修改人、修改时间、修改内容
- 保留所有历史版本，便于追溯
- 建立版本对比机制

**草稿命名**:
- 标准格式: 文件名_文种_v版本号_修改日期
- 示例: 关于XX的请示_v1.0_20260403.doc

#### 8.2 定稿标识

**定稿要求**:
- 经单位负责人签发后确定为定稿
- 标注"定稿"字样和签发人、签发日期
- 定稿后不得随意修改，如需修改需重新签发

**定稿标识位置**:
- 在文件标题右侧或右下角标注"定稿"
- 签发人签署在成文日期之上
- 签发日期与成文日期一致或早于成文日期

#### 8.3 归档管理

**归档范围**:
- 所有正式发文
- 重要的请示、报告
- 会议纪要
- 其他有保存价值的公文

**归档要求**:
- 按照文书档案管理规定进行归档
- 建立电子档案和纸质档案双轨制
- 保证档案的完整性和安全性

**保管期限**:
- 永久: 重要的方针政策性文件
- 30年: 重要的业务性文件
- 10年: 一般业务性文件

## 学习建议

1. **熟读规范文件**: 认真学习《党政机关公文处理工作条例》和《党政机关公文格式》
2. **多看范文**: 阅读权威机关发布的公文，学习规范表述
3. **对照检查**: 写作完成后对照本文档的检查清单进行自查
4. **总结反思**: 记录写作中的错误，避免重复犯错
5. **持续学习**: 公文规范不断更新，要持续学习新的要求
