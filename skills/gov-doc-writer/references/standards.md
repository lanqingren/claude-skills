## 概览
本文档规定了党政机关公文的格式标准，依据《党政机关公文格式》（GB/T 9704-2012）国家标准。

## 核心内容

### 1. 纸张要求

**规格**: A4型纸张（210mm × 297mm）
**质量**: 采用质量不低于60g/m²的胶版印刷纸或复印纸
**方向**: 纵向使用

### 2. 版式编排

**页边距**:
- 上白边（天头）: 37mm ± 1mm
- 下白边（地脚）: 35mm ± 1mm
- 左白边（订口）: 28mm ± 1mm
- 右白边（翻口）: 26mm ± 1mm

**版心尺寸**: 156mm × 225mm（不含页码）
**行距**: 正文行距一般固定值28-30磅，标题行距可适当加大

### 3. 字体字号

| 部分 | 字体 | 字号 | 颜色 |
|------|------|------|------|
| 标题 | 方正小标宋简体 | 二号 | 黑色 |
| 主送机关 | 仿宋GB2312 | 三号 | 黑色 |
| 正文 | 仿宋GB2312 | 三号 | 黑色 |
| 一级标题 | 黑体 | 三号 | 黑色 |
| 二级标题 | 楷体GB2312 | 三号 | 黑色 |
| 三级标题 | 仿宋GB2312 | 三号加粗 | 黑色 |
| 发文机关署名 | 仿宋GB2312 | 三号 | 黑色 |
| 成文日期 | 仿宋GB2312 | 三号 | 黑色 |
| 页码 | 宋体阿拉伯数字 | 四号 | 黑色 |

### 4. 标题格式

**结构**: 发文机关 + 关于 + 事由 + 文种

**格式要求**:
- 一般用二号小标宋体字
- 编排于红色分隔线下空二行位置
- 分多行时，要排列对称、长短适宜、间距恰当
- 标题中除法规、规章名称加书名号外，一般不用标点符号

**示例**:
```
XX市人民政府关于进一步加强城市绿化工作的通知
XX市财政局关于追加智慧政务平台建设经费的请示
XX省教育厅关于印发XX省教育信息化发展规划的通知
```

**注意事项**:
- 避免事由冗长，一般不超过50字
- 文种要准确，不可混用
- "关于"与"申请"、"请求"等词不能重复使用

### 5. 主送机关

**位置**: 标题下空一行，左侧顶格编排
**字体**: 三号仿宋体
**标点**: 主送机关名称后用冒号

**格式要求**:
- 顶格编排
- 多个主送机关之间用逗号分隔
- 最后一个主送机关名称后标冒号
- 如需回行，仍顶格编排

**示例**:
```
各县（区）人民政府，市政府各部门、各直属机构:
```

**注意事项**:
- 请示只能写一个主送机关
- 根据需要标注主送机关的规范化简称或统称
- 同级机关之间用顿号分隔，不同级机关之间用逗号分隔

### 6. 正文格式

**位置**: 主送机关名称下空一行
**字体**: 三号仿宋体
**行距**: 固定值28-30磅

**段落格式**:
- 首行缩进2字符
- 段落之间不空行
- 段首不空格

**结构层次**:
- 一级标题: "一、"黑体
- 二级标题: "（一）"楷体
- 三级标题: "1." 仿宋体加粗
- 四级标题: "（1）" 仿宋体

**注意事项**:
- 正文中的数字，除成文日期、部分结构层次序数和在词、词组、惯用语、缩略语、具有修辞色彩语句中作为词素的数字必须使用汉字外，应使用阿拉伯数字
- 计量单位应当使用法定计量单位

### 7. 附件说明

**位置**: 正文下空一行，左空二字编排
**格式**: "附件：1. XXX"或"附件：XXX"

**要求**:
- 附件名称后不加标点符号
- 多个附件使用阿拉伯数字标注顺序号
- 附件名称较长需回行时，应与上一行附件名称的首字对齐

**示例**:
```
附件：1. XX市智慧政务平台建设实施方案
      2. XX市智慧政务平台建设资金预算表
```

**注意事项**:
- 如有附件，应在正文下空一行注明附件顺序和名称
- 附件说明中的附件名称应与附件标题一致

### 8. 发文机关署名

**位置**: 附件说明下空二至四行（不加盖公章）或附件说明下空二至三行（加盖公章）
**字体**: 三号仿宋体
**对齐**: 右空四字编排

**格式要求**:
- 使用发文机关全称或规范化简称
- 单一机关行文时，在正文（或附件说明）下空二至四行右空二字字编排发文机关署名
- 联合行文时，每行只编排一个机关署名，每行字数相等，对齐编排

**示例**:
```
                                      XX市人民政府
```

### 9. 成文日期

**位置**: 发文机关署名下一行
**字体**: 三号仿宋体
**对齐**: 右空四字编排

**格式要求**:
- 用阿拉伯数字标注年、月、日
- 年份应标全称，月、日不编虚位（即1不编为01）
- 成文日期右空四字编排

**示例**:
```
                                      2026年4月3日
```

### 10. 抄送机关

**位置**: 印发机关和印发日期之下一行
**字体**: 四号仿宋体
**对齐**: 左空一字

**格式要求**:
- "抄送"二字后加冒号和抄送机关名称
- 多个抄送机关之间用逗号分隔
- 回行时与冒号后的首字对齐
- 最后一个抄送机关名称后标句号

**示例**:
```
抄送：市委办公室，市人大常委会办公室，市政协办公室。
```

**注意事项**:
- 抄送机关指除主送机关外需要执行或知晓公文内容的其他机关
- 不应使用"抄报"、"抄送"、"报送"等词汇混合使用

### 11. 密级和保密期限

**位置**: 公文首页左上角
**字体**: 三号黑体
**格式**: 密级 + ★ + 保密期限

**密级分类**:
- 绝密
- 机密
- 秘密

**格式示例**:
```
绝密★10年
机密★5年
秘密★3年
```

**注意事项**:
- 涉密公文标注密级和保密期限
- 密级和保密期限之间用"★"分隔
- 保密期限中的数字用阿拉伯数字标注

### 12. 紧急程度

**位置**: 公文首页左上角（如同时标注密级，则密级在左上角第一行，紧急程度在第二行）
**字体**: 三号黑体

**紧急程度分类**:
- 特急
- 加急

**格式示例**:
```
特急
加急
```

**注意事项**:
- 根据公文送达和办理的时限要求标注紧急程度
- 紧急程度标注在公文首页左上角

### 13. 发文字号

**位置**: 公文首页分隔线（红色反线）以上
**格式**: 发文机关代字 + 年份 + 发文顺序号

**组成要素**:
- 发文机关代字: 选取发文机关名称中最具代表性的字，一般2-4个字
- 年份: 用六角括号"〔〕"括入，标全称
- 发文顺序号: 不编虚位，不加"第"字

**格式示例**:
```
国办发〔2026〕12号
X政发〔2026〕15号
X财〔2026〕28号
```

**注意事项**:
- 发文字号位于发文机关标志下空二行位置
- 发文字号居中排布
- 年份、发文顺序号用阿拉伯数字标注

### 14. 联合行文规范

**适用场景**: 两个或两个以上机关联合发文

**发文机关署名规则**:
- 主办机关排第一，协办机关按级别或协商顺序排列
- 每行只编排一个机关署名，字数相等，对齐编排
- 所有联合行文机关均需在成文日期之上署名

**发文字号规则**:
- 使用主办机关的发文字号
- 不并列多个文号
- 在标题中体现联合发文机关

**标题格式示例**:
```
XX市人民政府、XX市教育局关于加强校园安全工作的通知
```

**盖章要求**:
- 所有联合行文机关均需盖章
- 每个机关的印章单独盖在该机关署名上
- 印章之间不相交、不相切
- 印章上不压正文，下压成文日期

**行文规则**:
- 联合行文应当明确主办部门
- 涉及多部门职权范围内的事务，主办部门应主动与有关部门协商
- 经协商取得一致意见后，由主办部门联合有关部门行文
- 如有分歧，主办部门主要负责人应当出面协调，仍不能取得一致意见时，主办部门可以列明各方理据，提出建设性意见，并与有关部门会签后报请上级机关协调或裁定

**示例**:
```
XX市人民政府办公室、XX市教育局、XX市公安局
关于进一步加强校园安全管理工作的通知

各县（区）人民政府，市政府各部门、各直属机构：

为切实加强校园安全管理工作……现将有关事项通知如下：

一、……
二、……
三、……

                                      XX市人民政府办公室
                                      XX市教育局
                                      XX市公安局
                                      2026年4月3日
```

**注意事项**:
- 联合行文机关不宜过多，一般不超过5个
- 如确需超过5个机关联合行文，应当商请其他机关以抄送形式
- 联合行文时，各机关级别应当相当或相近

## 完整页面示例

```
绝密★10年                                    特急
国办发〔2026〕12号

          XX市人民政府关于进一步加强城市绿化工作的通知

各县（区）人民政府，市政府各部门、各直属机构：

为深入贯彻习近平生态文明思想，加快推进美丽XX建设，进一步提升城市绿化水平，改善人居环境，根据《城市绿化条例》及有关规定，现就加强城市绿化工作通知如下：

一、总体要求
（一）指导思想。以习近平新时代中国特色社会主义思想为指导……
（二）基本原则。坚持生态优先、绿色发展，坚持规划引领、科学布局……

二、主要任务
（一）加强规划管控。编制城市绿地系统专项规划……
（二）提升绿化品质。推进公园绿地建设，完善城市绿道系统……

三、保障措施
（一）加强组织领导。各级政府要将城市绿化工作纳入重要议事日程……

                                      2026年4月3日

抄送：市委办公室，市人大常委会办公室，市政协办公室，市纪委监委。
```

## 常见错误

1. 标题结构不完整（缺少发文机关、关于或文种）
2. 标题中"关于"与"申请"、"请求"重复使用
3. 主送机关格式不规范（未顶格、标点错误）
4. 正文段落首行缩进不统一
5. 结构层次序数使用混乱
6. 成文日期格式不正确（使用汉字、编虚位）
7. 发文字号年份括号错误（使用圆括号或方括号）
8. 抄送机关标注不规范（使用"抄报"等词汇）
9. 字体字号不符合国家标准
10. 页边距设置不标准

## 验证规则

- 标题: 必须包含"发文机关+关于+事由+文种"四要素，事由明确简洁
- 主送机关: 顶格编排，名称后用冒号，多个机关用逗号分隔
- 正文: 三号仿宋体，首行缩进2字符，行距固定值28-30磅
- 结构层次: 一级"一、"黑体，二级"（一）"楷体，三级"1."仿宋体加粗
- 成文日期: 阿拉伯数字，右空四字，不编虚位
- 发文字号: 代字+〔年份〕+顺序号，居中排布
