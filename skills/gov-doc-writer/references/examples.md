## 核心内容

### 1. 请示范例

**来源**: 市政府正式公文（模拟）

**范例**:

```
XX市财政局关于追加智慧政务平台建设经费的请示

市人民政府：

为贯彻落实《政务移动互联网应用程序规范化管理办法》（国办函〔2026〕12号）精神，加快推进数字政府建设，提升政务服务效率和群众满意度，我市拟启动智慧政务平台建设项目。该项目总投资估算5000万元，其中需市财政追加安排资金3000万元，用于平台开发、硬件采购、数据迁移、系统测试等支出。

该项目建成后，将实现政务服务"一网通办"，有效提升政务服务效率，为企业和群众提供更加便捷的服务，预计每年可节省行政成本800万元，服务满意度提升至95%以上。

鉴于项目建设时间紧、任务重，为确保项目顺利实施，特请示追加资金3000万元，从2026年财政预算中安排。

妥否，请批示。

XX市财政局
2026年4月3日
```

**范例特点**:
- 标题结构完整：发文机关+关于+事由+文种
- 请示缘由明确：引用政策文件，说明背景和必要性
- 请示事项具体：明确追加金额和用途
- 预期成效量化：说明投资回报
- 结尾用语规范：使用"妥否，请批示"

### 2. 报告范例

**来源**: 市教育局正式公文（模拟）

**范例**:

```
XX市教育局关于2025年度教育信息化工作情况的报告

市人民政府：

2025年，在市委、市政府的正确领导下，我市教育信息化工作坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻国家教育数字化战略行动，围绕"提质、增效、惠民"目标，扎实推进各项工作，取得了显著成效。现将有关情况报告如下：

一、工作进展情况

（一）基础设施不断完善。全市所有学校实现千兆网络接入，建成智慧教室500间，配备多媒体教学设备3000套，实现了"班班通"全覆盖。

（二）平台建设稳步推进。建成全市教育云平台，整合优质数字教育资源10万条，注册用户50万人，日均访问量突破100万人次。

（三）应用水平显著提升。开展教师信息技术应用能力培训2万人次，95%的教师能够熟练运用信息化手段开展教学，学生信息素养测评合格率达到98%。

二、取得成效

（一）教学质量持续提升。通过信息化手段优化教学过程，全市教学质量监测成绩同比提高8个百分点，学生满意度达到92%。

（二）管理效率明显提高。实现学籍管理、考试报名、成绩查询等业务线上办理，每年可节省行政成本200万元，办事时间缩短60%。

（三）教育公平有效促进。通过在线教育平台，农村学校学生享受到优质教育资源，城乡教育差距进一步缩小。

三、存在问题

虽然取得一定成效，但仍存在以下问题：一是部分学校信息化设备老化，更新换代压力较大；二是教师信息技术应用能力参差不齐，高水平信息化教师数量不足；三是网络安全防护能力有待加强，存在数据泄露风险。

四、下一步工作计划

（一）加大投入力度。2026年计划安排资金1000万元，用于学校信息化设备更新和网络安全建设。

（二）强化师资培训。实施教育信息化能力提升工程，培训教师5000人次，培养信息化骨干教师200名。

（三）完善保障机制。建立教育信息化工作联席会议制度，加强统筹协调，形成工作合力。

特此报告。

XX市教育局
2026年1月15日
```

**范例特点**:
- 结构清晰：背景→进展→成效→问题→计划
- 数据详实：使用具体数据说明成效
- 问题客观：实事求是反映存在的问题
- 措施具体：下一步计划有针对性、可操作

### 3. 通知范例

**来源**: 市政府办公室正式公文（模拟）

**范例**:

```
XX市人民政府办公室关于开展全市安全生产大检查的通知

各县（区）人民政府，市政府各部门、各直属机构：

为深刻吸取近期安全生产事故教训，切实加强全市安全生产工作，根据市委、市政府统一部署，决定在全市范围内开展安全生产大检查。现将有关事项通知如下：

一、检查范围和重点

（一）检查范围：全市所有生产经营单位，重点检查危险化学品、建筑施工、交通运输、消防安全、特种设备、非煤矿山等行业领域。

（二）检查重点：
1. 安全生产责任制落实情况
2. 安全隐患排查治理情况
3. 从业人员安全教育培训情况
4. 应急预案制定和演练情况
5. 特种设备检测检验情况

二、时间安排

本次大检查自本通知印发之日起至2026年5月31日结束，分三个阶段进行：
（一）自查自纠阶段（4月3日-4月15日）：各单位对照检查内容全面自查。
（二）重点检查阶段（4月16日-5月20日）：市、县两级组织联合检查组进行抽查。
（三）整改提升阶段（5月21日-5月31日）：对发现的问题进行整改，建立长效机制。

三、工作要求

（一）高度重视，加强领导。各级政府要将安全生产大检查作为当前重点工作，主要负责同志要亲自部署、亲自督查，确保检查工作取得实效。

（二）全面排查，不留死角。各单位要对照检查内容，逐项排查，建立隐患台账，明确整改责任和时限，做到隐患排查全覆盖、无遗漏。

（三）立行立改，确保实效。对检查发现的隐患，要立即整改，不能立即整改的要制定整改方案，明确整改措施、责任人和完成时限，限期整改到位。

（四）加强督导，严肃问责。市政府将组织督导组对各地、各部门检查情况进行督查，对工作不力、隐患整改不到位的，将严肃追究相关单位和人员责任。

四、材料报送

请各县（区）人民政府、市政府各部门于5月31日前将安全生产大检查工作总结报送市政府办公室。

特此通知。

XX市人民政府办公室
2026年4月3日
```

**范例特点**:
- 结构完整：依据→范围→时间→要求→报送
- 内容具体：明确检查范围、重点、时间和要求
- 责任明确：谁来做、做什么、何时完成
- 要求有力：既有安排部署，又有监督问责

XX人工智能研究院

市大数据局：

为贯彻落实国家教育数字化战略行动，科学编制我市教育信息化"十四五"规划，我局拟于近期开展教育信息化专项调研。鉴于贵局在信息化建设方面经验丰富，在数据资源共享、智慧城市建设等方面取得显著成效，特商请予以协助，具体事项如下：

一、调研时间
2026年4月15日至5月15日

二、调研内容
（一）我市信息化基础设施现状
（二）数据资源共享平台建设情况
（三）智慧城市应用场景建设经验
（四）网络安全保障措施

三、协助事项
（一）提供相关政策文件和统计数据
（二）安排相关业务处室负责人接受访谈
（三）协助走访智慧城市应用场景
（四）提供数据资源共享平台建设经验材料

四、联系方式
联系人：王XX
联系电话：XXXX-XXXXXXXX
电子邮箱：wangxx@xxx.gov.cn

请贵局予以支持，指定专人对接，并请于4月20日前反馈协助人员联系方式。

特此函告。

XX市教育局
2026年4月3日
```

**范例特点**:
- 语气平等：使用"商请"、"予以支持"等礼貌用语
- 事项明确：具体说明需要协助的内容
- 便于对接：提供详细的联系方式
- 期限合理：明确反馈时间

### 6. 意见范例

**来源**: 市政府正式公文（模拟）

**范例**:

```
XX市人民政府关于加快推进老旧小区改造提升工作的实施意见

各县（区）人民政府，市政府各部门、各直属机构：

为改善老旧小区居民生活环境，提升城市品质，增强群众获得感、幸福感和安全感，根据国家、省有关文件精神，结合我市实际，现就加快推进老旧小区改造提升工作提出如下实施意见。

一、总体要求

（一）指导思想。以习近平新时代中国特色社会主义思想为指导，坚持以人民为中心的发展思想，按照"政府引导、居民参与、因地制宜、分类推进"的原则，全面推进老旧小区改造提升工作。

（二）基本原则。
1. 坚持以人为本，尊重居民意愿。充分听取居民意见，解决群众最关心、最直接、最现实的问题。
2. 坚持因地制宜，分类施策。根据不同小区实际情况，制定个性化改造方案。
3. 坚持建管并重，长效管理。在改造硬件设施的同时，建立长效管理机制。
4. 坚持多方参与，共建共享。政府、市场、居民共同参与，共享改造成果。

（三）工作目标。到2028年底，完成全市2000年以前建成的老旧小区改造任务，涉及居民10万户，基本实现老旧小区"环境整洁、配套完善、管理有序、安全宜居"的目标。

二、主要任务

（一）基础设施改造。重点改造水、电、气、暖、通信等管网，实施雨污分流改造，完善消防设施，增加停车位，加装电梯等。

（二）环境整治提升。清理私搭乱建，整治环境卫生，完善绿化照明，优化空间布局，提升小区环境品质。

（三）服务设施完善。配建养老、托幼、医疗、文化、体育等公共服务设施，建设便民服务中心，完善社区服务功能。

（四）智能系统建设。推进智慧社区建设，安装智能门禁、视频监控、智能快递柜等，提升小区智能化水平。

三、保障措施

（一）加强组织领导。成立老旧小区改造工作领导小组，统筹协调解决重大问题。各县（区）政府要成立相应工作机构，明确责任分工，确保工作顺利推进。

（二）加大资金投入。建立"政府出资、社会参与、居民分担"的多元化资金筹措机制。市财政每年安排专项资金2亿元，用于老旧小区改造补助。鼓励社会资本参与改造，探索市场化运作模式。

（三）强化督导考核。将老旧小区改造工作纳入年度目标考核，建立定期调度、通报制度，对工作推进不力的单位和责任人进行约谈问责。

（四）加强宣传引导。充分利用各类媒体平台，宣传老旧小区改造政策和工作成效，营造良好社会氛围，提高居民参与积极性。
```

**范例特点**:
- 结构完整：指导思想→基本原则→目标→任务→措施
- 逻辑严密：层次清晰，环环相扣
- 措施具体：任务明确，责任清晰，有可操作性
- 语言规范：使用标准的公文表述

为表彰先进、树立榜样，进一步激发全市人民的劳动热情和创造活力，根据《XX市劳动模范评选管理办法》，经逐级推荐、严格审核、社会公示，市政府决定授予XXX等50名同志"2025年度XX市劳动模范"称号，授予XXX等20名同志"2025年度XX市先进工作者"称号。

希望受表彰的同志珍惜荣誉、戒骄戒躁，再接再厉、再创佳绩，在新的起点上作出新的更大贡献。全市广大干部职工要以受表彰的同志为榜样，学习他们爱岗敬业、争创一流的奋斗精神，学习他们勇于创新、追求卓越的进取精神，学习他们甘于奉献、服务人民的高尚品德，为建设现代化新XX而努力奋斗。

各级各部门要高度重视劳模工作，关心关爱劳模，落实劳模待遇，大力宣传劳模事迹，营造崇尚劳动、尊重劳动、关爱劳动者的良好社会氛围。

附件：1. 2025年度XX市劳动模范名单
      2. 2025年度XX市先进工作者名单

XX市人民政府
2026年4月28日
```

**范例特点**:
- 权威性强：使用"决定"这一具有强制性的文种
- 态度明确：直接宣布表彰决定
- 号召有力：对受表彰者和全市干部职工提出明确要求

## 学习建议

1. **精读范文**：仔细阅读范例，体会公文的语言风格和结构安排
2. **对比分析**：对比不同文种的特点，理解各自的适用场景
3. **模仿练习**：参考范例的结构和表述，进行公文写作练习
4. **注意规范**：范例中体现的格式规范、语言规范是重点学习内容
5. **积累素材**：将范例中的优秀表述积累起来，用于自己的写作

## 注意事项

- 所有范例均为模拟或脱敏处理，实际使用时请根据具体情况调整
- 范例中的数据、时间、地点等均为虚构，仅供参考
- 学习范例时要结合具体情境，不能生搬硬套
