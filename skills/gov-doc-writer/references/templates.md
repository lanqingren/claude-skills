## 概览
本文档提供各文种公文的标准写作框架模板，包含结构要点和内容提示，便于快速生成符合规范的公文框架。

## 核心内容

### 1. 请示模板

**适用场景**: 向上级机关请求指示、批准

**结构框架**:
```
标题：XX机关关于XX（事由）的请示

主送机关：XX上级机关

正文第一段（请示缘由）：
【写作提示】阐述请示的背景、依据和必要性
【常见表述】"根据……精神，为……需要，现就……请示如下："

正文第二段（请示事项）：
【写作提示】清晰明确地陈述请求事项，一事一请
【常见表述】"拟……具体如下：1. …… 2. …… 3. ……"

正文第三段（请示理由）：
【写作提示】说明请示的理由、可行性、必要性
【常见表述】"该事项具有……必要性，主要理由如下：一是……二是……三是……"

正文第四段（预期成效/风险说明）：
【写作提示】说明批准后的预期成效或不批准的可能影响
【常见表述】"如获批准，将……"

结尾：妥否，请批示 / 是否可行，请批示

发文机关署名：XX机关

成文日期：X年X月X日
```

**内容填充引导**:
- 事由: 具体明确，不超过30字
- 依据: 引用相关文件、会议精神或政策要求
- 必要性: 说明为什么要请示，紧迫性如何
- 可行性: 说明请示事项的可行性、风险可控
- 请求事项: 具体明确，数量、金额、时间等要素清晰
- 预期成效: 批准后能取得什么效果

**注意事项**:
- 一文一事，一事一请
- 只写一个主送机关
- 事前行文，不得先斩后奏
- 语气谦恭，结尾要有请求语

### 2. 报告模板

**适用场景**: 向上级机关汇报工作、反映情况，回复上级机关询问

**结构框架**:
```
标题：XX机关关于XX（事项）的报告

主送机关：XX上级机关

正文第一段（工作背景）：
【写作提示】说明工作开展的背景、依据和总体情况
【常见表述】"根据……部署，我机关……现将有关情况报告如下："

正文第二段（工作开展情况）：
【写作提示】详细汇报工作进展、采取的措施、取得的成效
【常见表述】"一是……二是……三是……"
【内容要点】工作目标、主要做法、创新举措、推进情况

正文第三段（取得成效）：
【写作提示】用数据、事实说明工作成效
【常见表述】"截至……，累计……成效显著……"
【内容要点】量化指标、典型案例、社会反响

正文第四段（存在问题和困难）：
【写作提示】实事求是地反映存在的问题
【常见表述】"虽然取得一定成效，但仍存在……问题"
【内容要点】主要问题、原因分析、面临的困难

正文第五段（下一步工作计划）：
【写作提示】提出下一步工作思路和具体措施
【常见表述】"下一步，我机关将……"
【内容要点】工作目标、重点任务、保障措施

结尾：特此报告 / 以上报告，请审阅

发文机关署名：XX机关

成文日期：X年X月X日
```

**内容填充引导**:
- 背景: 工作开展的宏观背景和直接原因
- 工作情况: 具体做法、步骤、措施
- 成效: 用数据说话，量化成果
- 问题: 客观反映，不回避问题
- 计划: 有针对性，具体可行

**注意事项**:
- 不夹带请示事项
- 内容实事求是，不夸大不缩小
- 重点突出，条理清晰
- 上级机关一般不作批复

### 3. 通知模板

**适用场景**: 发布法规、转发文件、部署工作、告知事项

**结构框架**:
```
标题：XX机关关于XX（事项）的通知

主送机关：XX机关

正文第一段（通知依据）：
【写作提示】说明发布通知的依据和目的
【常见表述】"为……根据……精神，现就……有关事项通知如下："
【或转发性通知】"现将……转发给你们，请结合实际认真贯彻执行。"

正文第二段（通知事项）：
【写作提示】具体说明通知的主要事项
【常见表述】"一、…… 二、…… 三、……"
【内容要点】根据通知类型确定：
  - 指示性通知：工作任务、具体要求
  - 知照性通知：告知事项、时间地点
  - 任免通知：任免事项、生效时间

正文第三段（工作要求）：
【写作提示】提出贯彻落实的具体要求
【常见表述】"（一）提高认识，加强领导；（二）明确责任，抓好落实；（三）加强督导，确保实效"

正文第四段（执行时限）：
【写作提示】明确完成时间和上报要求
【常见表述】"请于X年X月X日前将……报送我机关"

结尾：特此通知

发文机关署名：XX机关（如需要）

成文日期：X年X月X日
```

**内容填充引导**:
- 依据: 法律法规、上级文件、会议精神
- 事项: 具体内容、目标任务、工作标准
- 要求: 如何做、做到什么程度、谁来负责
- 时限: 何时完成、何时上报、何时实施

**注意事项**:
- 事项要具体明确，便于执行
- 要求要有针对性，可操作性强
- 时限要合理，留有缓冲时间
- 语言简洁，条理清晰

### 4. 通报模板

**适用场景**: 表彰先进、批评错误、传达重要精神

**结构框架（表彰性通报）**:
```
标题：XX机关关于表彰XX的通报

主送机关：XX机关

正文第一段（通报缘由）：
【写作提示】说明表彰的背景和原因
【常见表述】"近期，……在……工作中表现突出，……"

正文第二段（先进事迹）：
【写作提示】详细描述先进事迹
【常见表述】"……同志在……工作中，……具体事迹如下：1. …… 2. …… 3. ……"

正文第三段（评价分析）：
【写作提示】对先进事迹进行评价和分析
【常见表述】"……同志的事迹充分体现了……精神，具有……特点"

正文第四段（表彰决定）：
【写作提示】宣布表彰决定和奖励措施
【常见表述】"为表彰先进，树立典型，决定授予……称号，并……"

正文第五段（学习号召）：
【写作提示】发出学习号召
【常见表述】"希望……珍惜荣誉，再接再厉。号召全体人员向……学习，……"

结尾：特此通报

发文机关署名：XX机关

成文日期：X年X月X日
```

**内容填充引导**:
- 事迹: 具体事例，有时间、地点、人物、事件
- 评价: 分析先进性、典型性、示范性
- 决定: 明确表彰形式和奖励内容
- 号召: 提出学习要求

### 5. 函模板

**适用场景**: 不相隶属机关之间商洽工作、询问答复、请求批准

**结构框架（商洽函）**:
```
标题：XX机关关于商请XX的函

主送机关：XX机关

正文第一段（函请缘由）：
【写作提示】说明发函的背景和目的
【常见表述】"为……我机关拟……鉴于贵机关在……方面经验丰富，特商请予以协助。"

正文第二段（具体事项）：
【写作提示】详细说明商请的具体事项
【常见表述】"具体事项如下：1. …… 2. …… 3. ……"

正文第三段（协助要求）：
【写作提示】明确希望对方如何协助
【常见表述】"请贵机关……并请于……前反馈……"

正文第四段（联系方式）：
【写作提示】提供对接人和联系方式
【常见表述】"联系人：XXX，联系电话：XXXXXXXXXXX"

结尾：特此函告 / 望予支持 / 请予函复

发文机关署名：XX机关

成文日期：X年X月X日
```

**内容填充引导**:
- 缘由: 为什么需要对方协助
- 事项: 具体需要做什么
- 要求: 如何做、何时做、达到什么标准
- 联系: 明确对接人

**注意事项**:
- 语气平等、礼貌、诚恳
- 事项具体明确，便于对方理解
- 不要提出超出对方能力范围的要求

### 6. 意见模板

**适用场景**: 对重要问题提出见解和处理办法

**结构框架**:
```
标题：XX机关关于XX的意见

主送机关：XX机关

正文第一段（问题背景）：
【写作提示】分析问题的现状、原因和影响
【常见表述】"近年来，……取得了显著成效，但也存在……问题，主要表现在……"

正文第二段（总体要求）：
【写作提示】提出指导思想、基本原则、工作目标
【常见表述】"一、总体要求。（一）指导思想。……（二）基本原则。1. …… 2. ……（三）工作目标。到……，……"

正文第三段（主要任务）：
【写作提示】提出具体任务和措施
【常见表述】"二、主要任务。（一）……（二）……（三）……"

正文第四段（保障措施）：
【写作提示】提出组织、政策、资金等保障措施
【常见表述】"三、保障措施。（一）加强组织领导。……（二）加大资金投入。……（三）强化督导考核。……"

结尾：（一般无固定结尾用语）

发文机关署名：XX机关

成文日期：X年X月X日
```

### 8. 其他文种模板

#### 决议模板

**适用场景**: 经会议讨论通过的重要决策事项

**结构框架**:
```
标题：关于XX的决议

正文第一段（会议基本情况）：
【写作提示】说明会议的时间、地点、参会情况和审议事项
【常见表述】"X年X月X日，XX会议在XX召开。会议应到XX人，实到XX人，符合法定人数。会议审议了XX事项，经充分讨论，作出如下决议："

正文第二段（会议认为）：
【写作提示】阐述会议对审议事项的分析、评价和判断
【常见表述】"会议认为，……（阐述背景、必要性、可行性等）"

正文第三段（会议决定）：
【写作提示】明确会议作出的决定内容
【常见表述】"会议决定，一、……；二、……；三、……"

正文第四段（执行要求）：
【写作提示】提出贯彻决议的要求
【常见表述】"会议要求，……（明确责任单位、完成时限、工作要求）"

正文第五段（表决情况）：
【写作提示】说明决议的表决通过情况
【常见表述】"本决议经XX会议表决通过（赞成XX票，反对XX票，弃权XX票）。"

结尾：（决议一般无固定结尾用语）

附：XX具体内容（如需要）
```

**内容填充引导**:
- 会议基本情况: 时间、地点、参会人数、主持人、审议事项
- 会议认为: 对事项的背景、意义、必要性的分析判断
- 会议决定: 明确具体的决定事项
- 执行要求: 责任单位、完成时限、工作标准
- 表决情况: 赞成、反对、弃权票数

**注意事项**:
- 必须经过会议讨论通过
- 决议具有权威性和严肃性
- 表决情况要如实记录
- 执行要求要具体明确

#### 命令（令）模板

**适用场景**: 公布行政法规和规章、宣布施行重大强制性行政措施、批准授予和晋升衔级、嘉奖有关单位和人员

**结构框架（公布令）**:
```
令第X号

《XX》已经X年X月X日XX会议通过，现予公布，自X年X月X日起施行。

机关首长：XXX
X年X月X日
```

**结构框架（行政令）**:
```
令第X号

为……，根据……规定，经……研究，决定……。具体事项如下：

一、……
二、……
三、……

此令。

机关首长：XXX
X年X月X日
```

**结构框架（嘉奖令）**:
```
令第X号

为表彰……，根据……规定，决定授予XX（单位/个人）XX称号，并给予XX奖励。

希望……珍惜荣誉，再接再厉，为……作出新的更大贡献。号召全体人员向……学习……

此令。

机关首长：XXX
X年X月X日
```

**内容填充引导**:
- 令号: 按顺序编号
- 公布内容: 法规规章名称、通过会议、施行日期
- 决定事项: 具体的行政措施或奖励内容
- 奖励内容: 奖励形式、奖励等级、具体措施

**注意事项**:
- 令号要连续编号
- 语言简明庄重
- 必须有机关首长署名
- 施行日期要明确

#### 公告模板

**适用场景**: 向国内外宣布重要事项或法定事项

**结构框架**:
```
标题：关于XX的公告

正文第一段（公告缘由）：
【写作提示】说明发布公告的依据和目的
【常见表述】"根据……规定，为……，现将……公告如下："

正文第二段（公告事项）：
【写作提示】明确公告的具体内容
【常见表述】"一、……；二、……；三、……"
【内容要点】公告的主体内容，分条列项，清晰明确

正文第三段（生效时间）：
【写作提示】说明公告的生效时间或有效期
【常见表述】"本公告自X年X月X日起施行"或"本公告有效期为X年"

正文第四段（其他说明）：
【写作提示】说明其他需要告知的事项
【常见表述】"特此公告。"或"本公告由XX负责解释。"

结尾：特此公告
```

**内容填充引导**:
- 依据: 法律法规、上级文件、会议决定
- 目的: 为什么要发布公告
- 事项: 具体公告内容，分条列项
- 生效时间: 施行日期或有效期
- 责任单位: 负责解释或执行的机关

**注意事项**:
- 面向国内外，不涉密
- 级别高，一般省、部级以上机关使用
- 语言简洁庄重
- 事项要明确具体

#### 通告模板

**适用场景**: 在一定范围内公布应当遵守或周知的事项

**结构框架**:
```
标题：关于XX的通告

正文第一段（通告依据）：
【写作提示】说明发布通告的依据和目的
【常见表述】"为……，根据……规定，现将有关事项通告如下："

正文第二段（通告事项）：
【写作提示】明确通告的具体内容和要求
【常见表述】"一、……；二、……；三、……"
【内容要点】需要遵守的规定、禁止的行为、执行的标准

正文第三段（违反后果）：
【写作提示】说明违反通告规定将承担的后果
【常见表述】"违反本通告规定的，将依法……"或"对违反本通告的行为，将……"

正文第四段（监督举报）：
【写作提示】说明监督举报的方式
【常见表述】"欢迎社会各界监督，举报电话：XXXX，举报邮箱：XXXX@XXX"

正文第五段（施行时间）：
【写作提示】说明通告的生效时间
【常见表述】"本通告自发布之日起施行。"

结尾：特此通告
```

**内容填充引导**:
- 依据: 法律法规、上级文件
- 目的: 为什么要发布通告
- 事项: 具体规定、禁止行为、执行标准
- 后果: 违反规定的法律责任或行政措施
- 监督: 举报方式、监督渠道
- 时间: 施行日期

**注意事项**:
- 适用于一定范围，具有约束力
- 违反后果要明确
- 常用于社会管理、治安、交通等领域
- 语言要严肃有力

#### 议案模板

**适用场景**: 各级人民政府按照法律程序向同级人民代表大会或人民代表大会常务委员会提请审议事项

**结构框架**:
```
标题：关于XX的议案

主送机关：XX人民代表大会/XX人民代表大会常务委员会

正文第一段（提案缘由）：
【写作提示】说明提出议案的背景、依据和必要性
【常见表述】"为……，根据……规定，XX政府审议通过了XX草案，现提请审议。"

正文第二段（议案内容）：
【写作提示】简述议案的主要内容
【常见表述】"XX草案主要包括……（概述主要内容）"

正文第三段（说明情况）：
【写作提示】说明草案的起草过程、征求意见情况等
【常见表述】"草案起草过程中，我们广泛征求了……意见，充分吸收了……建议。"

正文第四段（审议请求）：
【写作提示】明确提出审议请求
【常见表述】"现提请审议。"

结尾：现提请审议

附：XX草案及说明
```

**内容填充引导**:
- 背景: 为什么要提出议案
- 依据: 法律法规、上级文件
- 内容: 草案的主要内容概述
- 过程: 起草过程、征求意见情况
- 请求: 明确要求审议

**注意事项**:
- 仅限政府向人大或人大常委会行文
- 具有法定性和程序性
- 必须附上草案及说明
- 内容要符合法定程序

#### 批复模板

**适用场景**: 答复下级机关请示事项

**结构框架**:
```
标题：XX机关关于XX的批复

主送机关：XX机关（原请示机关）

正文第一段（批复依据）：
【写作提示】引用原请示，说明批复的依据
【常见表述】"你机关《关于……的请示》（X文〔2026〕X号）收悉。经研究，现批复如下："

正文第二段（批复意见）：
【写作提示】明确批复意见（同意、不同意或部分同意）
【常见表述】"一、同意你机关关于……的请示。"或"一、原则同意你机关关于……的请示，但需注意……"或"一、不同意你机关关于……的请示。"

正文第三段（具体要求）：
【写作提示】提出贯彻执行的具体要求
【常见表述】"二、……；三、……"
【内容要点】工作要求、执行标准、注意事项

正文第四段（监督要求）：
【写作提示】提出监督和报告要求
【常见表述】"请将……情况及时上报我机关。"

结尾：此复

发文机关署名：XX机关（如需要）
成文日期：X年X月X日
```

**内容填充引导**:
- 原请示: 准确引用原请示标题和文号
- 批复意见: 明确表态（同意/不同意/部分同意）
- 具体要求: 如何执行、达到什么标准
- 监督要求: 何时报告、如何监督

**注意事项**:
- 被动行文，必须有请示才有批复
- 一请一批，针对性强
- 批复态度要明确，不能含糊
- 要引用原请示文号

#### 纪要模板

**适用场景**: 记载、传达会议情况和议定事项

**结构框架**:
```
标题：XX会议纪要

正文第一部分（会议基本情况）：
【写作提示】记录会议的时间、地点、参会人员、主持人等
【常见格式】
一、会议基本情况
时间：X年X月X日 X时-X时
地点：XX会议室
参会人员：XX（职务）、XX（职务）、XX（职务）
主持人：XX
记录人：XX

正文第二部分（会议议程）：
【写作提示】列出会议的议程和议题
【常见格式】
二、会议议程
（一）审议XX事项
（二）讨论XX问题
（三）研究XX工作

正文第三部分（发言摘要）：
【写作提示】记录参会人员的主要发言要点
【常见格式】
三、发言摘要
（一）XX发言：……（要点1、要点2、要点3）
（二）XX发言：……（要点1、要点2、要点3）

正文第四部分（议定事项）：
【写作提示】明确会议议定的事项和责任分工
【常见格式】
四、议定事项
（一）……（责任单位：XX，完成时限：X年X月）
（二）……（责任单位：XX，完成时限：X年X月）
（三）……（责任单位：XX，完成时限：X年X月）

正文第五部分（落实要求）：
【写作提示】提出贯彻落实会议议定事项的要求
【常见格式】
五、落实要求
（一）各责任单位要……
（二）……部门要加强对……的督导检查
（三）建立定期调度机制，及时报告进展情况

落款：
主办单位：XX
X年X月X日
```

**内容填充引导**:
- 基本情况: 时间、地点、参会人员、主持人、记录人
- 议程: 会议讨论的主要议题
- 发言摘要: 主要观点、意见和建议
- 议定事项: 明确的决定事项、责任单位、完成时限
- 落实要求: 如何执行、监督机制、报告要求

**注意事项**:
- 客观记录会议情况，不添加个人观点
- 突出议定事项，这是会议纪要的核心
- 责任单位和完成时限要明确
- 发言摘要要简明扼要，突出重点
- 作为传达会议精神和执行依据

## 模板使用指南

1. **选择合适模板**: 根据文种和具体场景选择对应的模板
2. **填充内容提示**: 参考【写作提示】和【常见表述】填充内容
3. **结构调整**: 根据具体需要调整段落顺序和内容
4. **规范检查**: 填充完成后对照格式规范进行检查
5. **个性化调整**: 根据单位习惯和具体情况适当调整表述

## 注意事项

- 模板是框架，具体内容需要根据实际情况填充
- 避免照搬模板表述，要结合具体语境调整
- 保持公文格式的严肃性和规范性
- 特殊情况可适当调整结构，但要符合基本规范
