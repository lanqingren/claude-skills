## 概览
本文档收录公文写作中常用的专业术语、规范用语和常见表述，帮助提升公文的准确性和规范性。

## 核心内容

### 1. 常用术语

**公文行文类**:
- 上行文: 下级机关向上级机关报送的公文
- 下行文: 上级机关向下级机关发送的公文
- 平行文: 平级机关或不相隶属机关之间往来的公文
- 联合行文: 两个或两个以上机关联合发文

**公文要素类**:
- 发文机关: 制作并发送公文的机关
- 主送机关: 公文的主要受理机关
- 抄送机关: 除主送机关外需要执行或知晓公文内容的其他机关
- 发文字号: 公文发文机关标识下的编号
- 附件: 公文正文的说明、补充或参考资料
- 密级: 公文的保密等级

**公文处理类**:
- 拟稿: 起草公文的过程
- 审核: 对公文草稿进行审查核对
- 签发: 机关负责人对发出公文的批准
- 缮印: 制作公文正本的过程
- 发出: 公文正式发送的过程

### 2. 规范用语

**开头用语**:
- 根据法律、法规、政策时: "根据《……法》规定"、"按照……要求"
- 引用上级文件时: "根据《……通知》（X发〔2026〕X号）精神"
- 说明发文目的时: "为……"、"为做好……工作"、"为进一步……"
- 说明发文依据时: "根据……部署"、"按照……安排"

**过渡用语**:
- 展开论述时: "现就……有关事项通知如下"、"现将有关情况报告如下"
- 分项说明时: "一、……；二、……；三、……"
- 补充说明时: "此外，……"、"另外，……"
- 转换角度时: "与此同时，……"、"另一方面，……"

**结尾用语**:
- 请示结尾: "妥否，请批示"、"是否可行，请批示"、"以上请示，请予批准"
- 报告结尾: "特此报告"、"以上报告，请审阅"
- 通知结尾: "特此通知"
- 函结尾: "特此函告"、"特此函复"、"请予支持"、"请予函复"
- 通报结尾: "特此通报"
- 决定结尾: （一般无固定结尾用语）

**评价用语**:
- 肯定成绩时: "成效显著"、"进展顺利"、"取得了阶段性成果"
- 指出问题时: "存在……问题"、"有待进一步……"
- 提出希望时: "希望……"、"望……"
- 表示态度时: "应当……"、"必须……"、"要……"

**要求用语**:
- 提出要求时: "务必……"、"请……"、"要……"
- 强调重点时: "重点……"、"着力……"、"突出……"
- 明确责任时: "XX负责……"、"由XX牵头……"
- 规定时限时: "于……前完成"、"在……时限内……"

### 3. 常见表述

**请示常用表述**:
- 请示缘由: "为做好……工作，根据……精神，现就……请示如下"
- 必要性说明: "该事项具有……必要性，主要理由如下：一是……；二是……；三是……"
- 可行性说明: "经研究论证，该事项……可行，主要依据是……"
- 请求事项: "拟……具体如下：1. ……；2. ……；3. ……"
- 预期成效: "如获批准，将……"

**报告常用表述**:
- 工作开展: "根据……部署，我机关……现将有关情况报告如下"
- 主要做法: "一是……；二是……；三是……"
- 取得成效: "截至……，累计……成效显著"
- 存在问题: "虽然取得一定成效，但仍存在……问题，主要表现在……"
- 下一步计划: "下一步，我机关将……"

**通知常用表述**:
- 指示性通知: "为……，根据……精神，现就……有关事项通知如下"
- 转发性通知: "现将……转发给你们，请结合实际认真贯彻执行"
- 发布性通知: "《……》已经……审议通过，现予发布"
- 工作要求: "（一）提高认识，加强领导；（二）明确责任，抓好落实；（三）加强督导，确保实效"

**函常用表述**:
- 商洽函: "为……我机关拟……鉴于贵机关在……方面经验丰富，特商请予以协助"
- 询问函: "关于……问题，特向贵机关函询，请予函复"
- 答复函: "贵机关《关于……的函》（X函〔2026〕X号）收悉，经研究，现函复如下"
- 请批函: "关于……事项，特向贵机关请批，请予批准"

### 4. 数字与计量

**数字使用规范**:
- 使用阿拉伯数字的情况:
  - 统计表中的数值
  - 公历世纪、年代、年、月、日、时刻
  - 物理量量值
  - 计数单位前的数字
  - 部队番号、文件编号、证件号码等
- 使用汉字数字的情况:
  - 定型的词、词组、成语、惯用语
  - 相邻两个数字连用表示概数（必须用汉字，不要加顿号）
  - 带有"几"字的数字表示约数
  - 星期几
  - 非公历经年

**计量单位使用规范**:
- 使用法定计量单位
- 常见计量单位示例:
  - 长度: 千米、米、厘米、毫米
  - 重量: 吨、千克、克
  - 面积: 平方千米、公顷、平方米
  - 体积: 立方米、升
  - 时间: 年、天、小时、分钟
  - 货币: 元、角、分

**数字书写规范**:
- 4位以内数字不分节
- 5位以上数字分节，从右向左每3位一节，节间空四分之一汉字
- 小数点后保留位数根据需要确定，一般不超过2位
- 百分数保留整数或1位小数
- 金额数字: 大写金额规范书写

**示例**:
```
2026年4月3日（正确）
2026.04.03（错误）

12.3亿元（正确）
12.30亿元（不必要）

3456人（正确）
3，456人（错误）

1.5万亿元（正确）
1.5万亿（不严谨）

三五天（正确）
三、五天（错误）
```

### 5. 时间表述

**时间规范**:
- 年份: 使用四位阿拉伯数字，如"2026年"
- 月份: 使用汉字或阿拉伯数字，如"4月"或"04月"
- 日期: 使用阿拉伯数字，如"3日"
- 时段: 如"2026年4月"或"2026年4月1日至2026年4月30日"
- 时点: 如"2026年4月3日10时30分"

**常见时间表述**:
- 近期: 指较近的一段时间（通常指1-3个月）
- 近期以来: 从某个较近的时间到现在
- 上半年: 1月至6月
- 下半年: 7月至12月
- 前三季度: 1月至9月
- 年底/年末: 12月
- "十一五"期间: 2006年至2010年
- "十四五"时期: 2021年至2025年

**时间表述示例**:
```
2026年4月3日（正确）
2026.04.03（错误）

2026年上半年（正确）
2026年上年度（错误）

"十四五"时期（正确）
"十四五"期间（正确）
"十四五"时间内（错误）

截至2026年3月底（正确）
截至到2026年3月底（错误）
```

## 常见错误

1. **开头用语不规范**: "为了"与"为"混用，"根据"与"按照"不分
2. **结尾用语错误**: 请示结尾用"特此报告"，报告结尾用"妥否请批示"
3. **数字书写不规范**: 分节错误，计量单位不统一
4. **时间表述不准确**: "截至"后加"到"，"期间"与"时期"混淆
5. **评价用语不当**: 夸大成绩，回避问题
6. **要求用语模糊**: "要……"、"应当……"混用，责任主体不明确

## 使用建议

1. 根据文种选择对应的规范用语
2. 保持全文用语风格统一
3. 准确使用术语，避免歧义
4. 数字和时间表述要规范统一
5. 评价要客观公正，要求要明确具体
