## 概览
本文档规定了党政机关15种公文的适用范围、行文规则和结构要点，依据《党政机关公文处理工作条例》。

## 核心内容

### 1. 决议

**适用范围**: 经会议讨论通过的重要决策事项
**行文规则**:
- 必须经过会议讨论通过
- 具有权威性和严肃性
- 适用于党委、人大等权力机关

**结构要点**:
- 标题: 关于XX的决议
- 正文: 会议基本情况→决策内容→执行要求
- 落款: 机关名称+日期

### 2. 决定

**适用范围**: 对重要事项作出决策和部署、奖惩有关单位和人员、变更或撤销下级不适当决定
**行文规则**:
- 适用于重大决策部署
- 具有强制性和执行性
- 可分为部署性决定、奖惩性决定、变更性决定

**结构要点**:
- 标题: 关于XX的决定
- 正文: 决定依据→决定事项→执行要求
- 结尾: 一般无固定结尾用语

### 3. 命令（令）

**适用范围**: 公布行政法规和规章、宣布施行重大强制性行政措施、批准授予和晋升衔级、嘉奖有关单位和人员
**行文规则**:
- 权限严格，仅限国务院及其各部门、县级以上政府
- 具有最高权威性和强制性
- 语言简明庄重

**结构要点**:
- 标题: 令号+关于XX的命令
- 正文: 命令依据→命令内容→执行要求
- 落款: 签发人+签发日期

### 4. 公报

**适用范围**: 公布重要决定或重大事项
**行文规则**:
- 公开性极强，面向社会
- 主要用于发布重要统计数据、国际条约、重要决定等

**结构要点**:
- 标题: 关于XX的公报
- 正文: 公布事项→具体情况→相关说明

### 5. 公告

**适用范围**: 向国内外宣布重要事项或法定事项
**行文规则**:
- 级别高，一般由省、部级以上机关使用
- 面向国内外公开
- 简洁庄重，不涉密

**结构要点**:
- 标题: 关于XX的公告
- 正文: 公告事项→具体内容→生效时间
- 结尾: 特此公告

### 6. 通告

**适用范围**: 在一定范围内公布应当遵守或周知的事项
**行文规则**:
- 适用于一定范围，不面向国内外
- 具有约束力，要求遵守
- 常用于社会管理、治安、交通等领域

**结构要点**:
- 标题: 关于XX的通告
- 正文: 通告依据→通告事项→违反后果
- 结尾: 特此通告

### 7. 意见

**适用范围**: 对重要问题提出见解和处理办法
**行文规则**:
- 具有指导性和参考性
- 可分指导性意见、建议性意见、批转性意见
- 既可以上行、下行，也可以平行

**结构要点**:
- 标题: 关于XX的意见
- 正文: 问题分析→处理意见→实施要求
- 结尾: 一般无固定结尾用语

### 8. 通知

**适用范围**: 发布法规、规章，转发上级机关、同级机关和不相隶属机关的公文，批转下级机关的公文，要求下级机关办理某项事务等
**行文规则**:
- 使用最广泛
- 具有指挥性和告知性
- 可分为发布性通知、转发性通知、批转性通知、指示性通知、知照性通知

**结构要点**:
- 标题: 关于XX的通知
- 正文: 通知依据→通知事项→具体要求→执行时限
- 结尾: 特此通知

### 9. 通报

**适用范围**: 表彰先进、批评错误、传达重要精神和告知重要情况
**行文规则**:
- 具有典型性和教育性
- 可分为表彰性通报、批评性通报、情况性通报
- 事实要具体，分析要透彻

**结构要点**:
- 标题: 关于XX的通报
- 正文: 通报缘由→事实陈述→分析评价→决定事项→学习/吸取教训要求
- 结尾: 特此通报

### 10. 报告

**适用范围**: 向上级机关汇报工作、反映情况，回复上级机关的询问
**行文规则**:
- 属于上行文
- 侧重汇报，不夹带请示事项
- 可以是综合报告、专题报告、答复报告
- 上级机关对报告一般不作批复

**结构要点**:
- 标题: 关于XX的报告
- 正文: 工作背景→工作情况→取得成效→存在问题→下一步计划
- 结尾: 特此报告 / 以上报告，请审阅

### 11. 请示

**适用范围**: 向上级机关请求指示、批准
**行文规则**:
- 属于上行文
- 一文一事，一事一请
- 事前行文，不得先斩后奏
- 只能写一个主送机关
- 一般不得越级请示
- 语气要谦恭，结尾要有请求语

**结构要点**:
- 标题: 关于XX的请示
- 主送机关: 一个上级机关
- 正文: 请示缘由→请示事项→请示理由→结语
- 结尾: 妥否，请批示 / 是否可行，请批示 / 以上请示，请予批准

### 12. 批复

**适用范围**: 答复下级机关请示事项
**行文规则**:
- 属于下行文
- 被动行文，必须有请示才有批复
- 一请一批，针对性强
- 批复态度要明确，同意、不同意或部分同意要写清楚

**结构要点**:
- 标题: 关于XX的批复
- 主送机关: 原请示机关
- 正文: 批复依据（引用原请示）→批复意见→批复理由→执行要求
- 结尾: 此复

### 13. 议案

**适用范围**: 各级人民政府按照法律程序向同级人民代表大会或人民代表大会常务委员会提请审议事项
**行文规则**:
- 仅限政府向人大或人大常委会行文
- 具有法定性和程序性
- 适用于提请审议法律法规、重大事项、人事任免等

**结构要点**:
- 标题: 关于XX的议案
- 主送机关: XX人民代表大会/人大常委会
- 正文: 提案依据→议案内容→审议请求
- 结尾: 现提请审议

### 14. 函

**适用范围**: 不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项
**行文规则**:
- 属于平行文，也适用于不相隶属机关之间的上行、下行
- 使用灵活，适用范围广
- 语气要平等、礼貌、诚恳
- 可分为商洽函、询问函、答复函、请批函、告知函

**结构要点**:
- 标题: 关于XX的函
- 主送机关: 不相隶属机关
- 正文: 函请/函商/函告缘由→具体事项→意见建议→希望要求
- 结尾: 特此函告 / 特此函复 / 请予支持 / 请予函复

### 15. 纪要

**适用范围**: 记载、传达会议情况和议定事项
**行文规则**:
- 客观记录会议情况
- 突出议定事项
- 适用于各级各类会议
- 作为传达会议精神和执行依据

**结构要点**:
- 标题: XX会议纪要
- 正文: 会议基本情况（时间、地点、参会人员）→会议议程→发言摘要→议定事项→落实要求
- 落款: 会议主办单位+日期

## 常见区别对比

### 请示 vs 报告
- **请示**: 请求指示、批准，需要上级回复，一文一事
- **报告**: 汇报工作、反映情况，不需要回复，可以综合反映

### 公告 vs 通告
- **公告**: 面向国内外，级别高，事项重大
- **通告**: 面向一定范围，具有约束力，要求遵守

### 通知 vs 通报
- **通知**: 部署工作、传达事项，侧重告知和要求
- **通报**: 表彰先进、批评错误、传达精神，侧重教育和典型

### 意见 vs 决定
- **意见**: 提出见解和处理办法，具有指导性和参考性
- **决定**: 对重要事项作出决策，具有强制性和执行性

## 示例

### 请示示例
```
XX市财政局关于追加智慧政务平台建设经费的请示

市人民政府:

为贯彻落实《政务移动互联网应用程序规范化管理办法》（国办函〔2026〕12号）精神，加快推进数字政府建设，我市拟启动智慧政务平台建设项目。该项目总投资估算XX万元，其中需市财政追加安排资金XX万元，用于平台开发、硬件采购、数据迁移等支出。项目建成后，将有效提升政务服务效率，为企业和群众提供更加便捷的服务。

以上请示，是否可行，请批示。

XX市财政局
2026年4月3日
```

### 通知示例
```
XX市人民政府办公室关于开展安全生产大检查的通知

各县（区）人民政府，市政府各部门、各直属机构:

为深刻吸取近期安全生产事故教训，切实加强全市安全生产工作，根据市委、市政府统一部署，决定在全市范围内开展安全生产大检查。现将有关事项通知如下:

一、检查范围
全市所有生产经营单位，重点检查危险化学品、建筑施工、交通运输、消防安全等行业领域。

二、检查内容
（一）安全生产责任制落实情况
（二）安全隐患排查治理情况
（三）应急处置能力建设情况
（四）从业人员安全教育培训情况

三、工作要求
（一）高度重视，加强领导
（二）全面排查，不留死角
（三）立行立改，确保实效
（四）加强督导，严肃问责

本次大检查自本通知印发之日起至XX月XX日结束，请各单位于XX月XX日前将检查情况报送市政府办公室。

特此通知。

XX市人民政府办公室
2026年4月3日
```

### 函示例
```
XX市教育局关于商请协助开展教育信息化调研的函

市大数据局:

为贯彻落实国家教育数字化战略行动，科学编制我市教育信息化发展规划，我局拟开展教育信息化专项调研。鉴于贵局在信息化建设方面经验丰富，特商请予以协助，具体事项如下:

一、调研时间
2026年4月中旬至5月中旬

二、调研内容
（一）我市信息化基础设施现状
（二）数据资源共享平台建设情况
（三）网络安全保障措施

三、协助事项
（一）提供相关政策文件和统计数据
（二）安排相关人员接受访谈
（三）协助走访相关单位

请贵局予以支持，指定专人对接，并请于XX月XX日前反馈协助人员联系方式。

特此函告。

XX市教育局
2026年4月3日
```
