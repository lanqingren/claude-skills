## 概览

## 核心内容

### 1. 请示结尾用语

**标准结尾**:
- 妥否，请批示
- 是否可行，请批示
- 以上请示，请予批准
- 以上请示，当否，请批示
- 妥否，请批复

**使用场景**:
- 请求批准事项: "以上请示，请予批准"
- 请求指示事项: "妥否，请批示"
- 询问是否可行: "是否可行，请批示"

**注意事项**:
- 请示必须有结尾用语
- 结尾用语要谦恭，体现请示的语气
- 不要省略"请"字
- 不要使用报告类的结尾用语

**示例**:
```
……（请示事项具体内容）

以上请示，妥否，请批示。

XX市财政局
2026年4月3日
```

### 2. 报告结尾用语

**标准结尾**:
- 特此报告
- 以上报告，请审阅
- 以上报告，如有不当，请指正

**使用场景**:
- 一般汇报工作: "特此报告"
- 详细报告情况: "以上报告，请审阅"
- 请求上级审阅: "以上报告，请审阅"

**注意事项**:
- 报告结尾用语相对简单
- 不要夹带请示内容
- 不要使用"请批示"等请示用语
- 结尾要简洁庄重

**示例**:
```
……（报告具体内容）

以上报告，请审阅。

XX市教育局
2026年4月3日
```

### 3. 通知结尾用语

**标准结尾**:
- 特此通知

**使用场景**:
- 所有类型的通知都使用此结尾

**注意事项**:
- 通知结尾用语统一为"特此通知"
- 不要添加其他修饰语
- 结尾要简洁明确

**示例**:
```
……（通知具体内容）

特此通知。

XX市人民政府办公室
2026年4月3日
```

### 4. 通报结尾用语

**标准结尾**:
- 特此通报

**使用场景**:
- 表彰性通报
- 批评性通报
- 情况性通报

**注意事项**:
- 通报结尾用语统一为"特此通报"
- 表彰性通报可在结尾后添加号召性表述
- 批评性通报可在结尾后添加警示性表述

**示例（表彰性通报）**:
```
……（通报具体内容）

希望XX同志珍惜荣誉，再接再厉。号召全体人员向XX同志学习，立足岗位，创先争优，为……作出新的更大贡献。

特此通报。

XX市人民政府
2026年4月3日
```

**示例（批评性通报）**:
```
……（通报具体内容）

各地区、各部门要引以为戒，举一反三，切实加强……，坚决防止类似问题再次发生。

特此通报。

XX市纪委监委
2026年4月3日
```

### 5. 函结尾用语

**标准结尾**:
- 商洽函: 特此函告 / 望予支持 / 请予协助
- 询问函: 请予函复
- 答复函: 特此函复
- 请批函: 请予批准 / 望予批准
- 告知函: 特此函告 / 特此函知

**使用场景**:
- 商洽工作: "特此函告"、"望予支持"
- 询问事项: "请予函复"
- 答复询问: "特此函复"
- 请求批准: "请予批准"
- 告知事项: "特此函告"

**注意事项**:
- 根据函的类型选择对应的结尾用语
- 语气要平等、礼貌、诚恳
- 不要使用命令式语气

**示例（商洽函）**:
```
……（函具体内容）

请贵机关予以支持，指定专人对接，并请于……前反馈协助人员联系方式。

特此函告。

XX市教育局
2026年4月3日
```

**示例（询问函）**:
```
……（函具体内容）

以上问题，请贵机关研究后予以函复。

XX市人力资源和社会保障局
2026年4月3日
```

**示例（答复函）**:
```
……（函具体内容）

此复。

XX市人民政府办公室
2026年4月3日
```

### 6. 意见结尾用语

**标准结尾**:
- （意见一般无固定结尾用语）

**使用场景**:
- 意见类公文通常在正文中明确要求后自然结束，不使用固定结尾用语

**注意事项**:
- 意见结尾较为灵活
- 可在最后一段提出总体要求
- 不要添加"特此意见"等不规范表述

**示例**:
```
……（意见具体内容）

各地区、各部门要高度重视……，加强组织领导，明确责任分工，细化工作措施，确保各项任务落到实处。

XX市人民政府
2026年4月3日
```

## 结尾用语使用规则

### 通用规则
1. **文种对应**: 结尾用语必须与文种对应，不能混用
2. **格式规范**: 结尾用语另起一行，顶格或空二格书写
3. **简洁庄重**: 结尾用语要简洁、庄重，不冗长
4. **语气得体**: 根据文种选择合适的语气（谦恭、平等、严肃）

### 特殊情况处理
1. **联合行文**: 结尾用语与单个机关行文相同
2. **涉外公文**: 结尾用语可适当调整，但要保持庄重
3. **紧急公文**: 结尾用语不因紧急而省略

### 常见错误
1. **文种不匹配**: 请示用"特此报告"，报告用"妥否请批示"
2. **用语冗长**: "特此报告，请审阅指正"（冗余）
3. **缺少结尾**: 请示、报告、通知等文种缺少结尾用语
4. **语气不当**: 函中使用命令式结尾用语

## 示例对比

### 正确示例
```
请示：
……
以上请示，妥否，请批示。

报告：
……
特此报告。

通知：
……
特此通知。

函：
……
特此函告。
```

### 错误示例
```
请示：
……
特此报告。（错误：文种不匹配）

报告：
……
妥否，请批示。（错误：文种不匹配）

通知：
……
以上通知，请认真贯彻执行。（错误：冗余）

函：
……
请予批示。（错误：语气不当）
```

- [ ] 语气是否得体
- [ ] 是否省略了必要的结尾用语
- [ ] 结尾用语是否简洁不冗余
